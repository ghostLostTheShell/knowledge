在长期运行的应用程序中，高效地管理资源至关重要，特别是在构建大规模系统时。如果像 Socket 连接、数据库连接或文件描述符之类的资源没有得到妥善管理，可能会导致资源泄漏，从而降低应用程序的性能和可靠性。Effect 提供的结构有助于确保资源得到妥善管理和释放，即使在发生异常的情况下也是如此。

通过确保每次获取资源时都有相应的释放机制，Effect 简化了应用程序中的资源管理过程。

## 终结化 (Finalization)

在许多编程语言中，`try` / `finally` 结构确保无论操作成功还是失败，清理代码都会运行。Effect 通过 `Effect.ensuring`、`Effect.onExit` 和 `Effect.onError` 提供了类似的功能。

### ensuring

`Effect.ensuring` 函数保证无论主 Effect 成功、失败还是被中断，终结器 (finalizer) Effect 都会运行。

这对于执行清理操作非常有用，例如关闭文件句柄、记录日志消息或释放锁。

如果你需要访问 Effect 的执行结果，请考虑使用 [onExit](#onexit)。

**示例**（在所有结果中运行终结器）

```ts twoslash
import { Console, Effect } from "effect"

// 定义一个清理 Effect
const handler = Effect.ensuring(Console.log("清理完成"))

// 定义一个成功的 Effect
const success = Console.log("任务完成").pipe(
  Effect.as("某些结果"),
  handler
)

Effect.runFork(success)
/*
输出:
任务完成
清理完成
*/

// 定义一个失败的 Effect
const failure = Console.log("任务失败").pipe(
  Effect.andThen(Effect.fail("某些错误")),
  handler
)

Effect.runFork(failure)
/*
输出:
任务失败
清理完成
*/

// 定义一个被中断的 Effect
const interruption = Console.log("任务被中断").pipe(
  Effect.andThen(Effect.interrupt),
  handler
)

Effect.runFork(interruption)
/*
输出:
任务被中断
清理完成
*/
```

### onExit

`Effect.onExit` 允许你在主 Effect 完成后运行一个清理 Effect，并接收一个描述结果的 [Exit](/docs/data-types/exit/) 值。

- 如果 Effect 成功，`Exit` 包含成功值。
- 如果失败，`Exit` 包含错误或失败原因 (cause)。
- 如果被中断，`Exit` 会反映该中断状态。

清理步骤本身是不可中断的，这有助于在复杂或高并发的情况下管理资源。

**示例**（使用 Effect 的结果运行清理函数）

```ts twoslash
import { Console, Effect, Exit } from "effect"

// 定义一个记录结果的清理 Effect
const handler = Effect.onExit((exit) =>
  Console.log(`清理完成: ${Exit.getOrElse(exit, String)}`)
)

// 定义一个成功的 Effect
const success = Console.log("任务完成").pipe(
  Effect.as("某些结果"),
  handler
)

Effect.runFork(success)
/*
输出:
任务完成
清理完成: 某些结果
*/

// 定义一个失败的 Effect
const failure = Console.log("任务失败").pipe(
  Effect.andThen(Effect.fail("某些错误")),
  handler
)

Effect.runFork(failure)
/*
输出:
任务失败
清理完成: Error: 某些错误
*/

// 定义一个被中断的 Effect
const interruption = Console.log("任务被中断").pipe(
  Effect.andThen(Effect.interrupt),
  handler
)

Effect.runFork(interruption)
/*
输出:
任务被中断
清理完成: 所有 fiber 已被中断且无错误。
*/
```

### onError

此函数允许你附加一个清理 Effect，每当调用它的 Effect 失败时该清理 Effect 都会运行，并将失败原因 (cause) 传递给它。

你可以使用它来执行记录日志、释放资源或应用额外的恢复步骤。

如果失败是由中断引起的，该清理 Effect 也会运行。它是不可中断的，因此一旦开始就总会执行完成。

**示例**（仅在失败时运行清理）

```ts twoslash
import { Console, Effect } from "effect"

// 当 Effect 失败时，此处理器记录失败原因
const handler = Effect.onError((cause) =>
  Console.log(`清理完成: ${cause}`)
)

// 定义一个成功的 Effect
const success = Console.log("任务完成").pipe(
  Effect.as("某些结果"),
  handler
)

Effect.runFork(success)
/*
输出:
任务完成
*/

// 定义一个失败的 Effect
const failure = Console.log("任务失败").pipe(
  Effect.andThen(Effect.fail("某些错误")),
  handler
)

Effect.runFork(failure)
/*
输出:
任务失败
清理完成: Error: 某些错误
*/

// 定义一个因缺陷（defect）而失败的 Effect
const defect = Console.log("任务因缺陷失败").pipe(
  Effect.andThen(Effect.die("炸了！")),
  handler
)

Effect.runFork(defect)
/*
输出:
任务因缺陷失败
清理完成: Error: 炸了！
*/

// 定义一个被中断的 Effect
const interruption = Console.log("任务被中断").pipe(
  Effect.andThen(Effect.interrupt),
  handler
)

Effect.runFork(interruption)
/*
输出:
任务被中断
清理完成: 所有 fiber 已被中断且无错误。
*/
```

## acquireUseRelease (获取-使用-释放)

许多现实世界的操作涉及处理必须在不再需要时释放的资源，例如：

- 数据库连接
- 文件句柄
- 网络请求

Effect 提供了 `Effect.acquireUseRelease`，确保资源被：

1. 正确地**获取** (Acquire)。
2. 用于预定的目的 (**使用** Use)。
3. 即使发生错误也会被**释放** (Release)。

**语法**

```ts showLineNumbers=false
Effect.acquireUseRelease(acquire, use, release)
```

**示例**（自动管理资源生命周期）

```ts twoslash
import { Effect, Console } from "effect"

// 定义一个资源接口
interface MyResource {
  readonly contents: string
  readonly close: () => Promise<void>
}

// 模拟资源获取
const getMyResource = (): Promise<MyResource> =>
  Promise.resolve({
    contents: "lorem ipsum",
    close: () =>
      new Promise((resolve) => {
        console.log("资源已释放")
        resolve()
      })
  })

// 定义如何获取资源
const acquire = Effect.tryPromise({
  try: () =>
    getMyResource().then((res) => {
      console.log("资源已获取")
      return res
    }),
  catch: () => new Error("获取资源错误")
})

// 定义如何释放资源
const release = (res: MyResource) => Effect.promise(() => res.close())

const use = (res: MyResource) => Console.log(`内容是 ${res.contents}`)

//      ┌─── Effect<void, Error, never>
//      ▼
const program = Effect.acquireUseRelease(acquire, use, release)

Effect.runPromise(program)
/*
输出:
资源已获取
内容是 lorem ipsum
资源已释放
*/
```
