# 使用生成器

Effect 提供了一种方便的语法，类似于 `async`/`await`，使用 [生成器](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Generator) 编写带有效果（effectful）的代码。

---
**可选功能**

> 在 Effect 中使用生成器是一个可选功能。如果您不熟悉生成器或偏好其他编码风格，可以探索 Effect 中关于 [构建管道](/docs/getting-started/building-pipelines/) 的文档。
---
## 理解 Effect.gen

`Effect.gen` 工具通过利用 JavaScript 的生成器函数简化编写带有效果的代码。这种方法使您的代码看起来和行为更像传统同步代码，既增强了可读性又改善了错误管理。

**示例**（带折扣的交易处理）

让我们探索一个实际程序，该程序执行一系列常见于应用逻辑的数据转换：

```typescript
import { Effect } from "effect"

// 添加服务费的函数
const addServiceCharge: (amount: number) => number = (amount: number) => amount + 1

// 安全计算折扣的函数
const applyDiscount: (total: number, discountRate: number) => Effect.Effect<number, Error> = (
  total: number,
  discountRate: number
): Effect<number, Error> => 
  discountRate === 0
    ? Effect.fail(new Error("折扣率不能为零"))
    : Effect.succeed(total - (total * discountRate) / 100)

// 模拟从数据库获取交易金额的异步任务
const fetchTransactionAmount: Effect.Effect<number, never, never> = Effect.promise(() => Promise.resolve(100))

// 模拟从配置文件获取折扣率的异步任务
const fetchDiscountRate: Effect.Effect<number, never, never> = Effect.promise(() => Promise.resolve(5))

// 使用生成器函数组装程序
const program: Effect.Effect<string, Error, never> = Effect.gen(function* () {
  // 获取交易金额
  const transactionAmount = yield* fetchTransactionAmount
  
  // 获取折扣率
  const discountRate = yield* fetchDiscountRate
  
  // 计算折扣金额
  const discountedAmount = yield* applyDiscount(
    transactionAmount,
    discountRate
  )
  
  // 应用服务费
  const finalAmount = addServiceCharge(discountedAmount)
  
  // 返回最终金额
  return `最终收费金额：${finalAmount}`
})

// 执行程序并输出结果
Effect.runPromise(program).then(console.log)
// 输出：最终收费金额：96
```

使用 `Effect.gen` 的关键步骤：

- 将您的逻辑包装在 `Effect.gen` 中
- 使用 `yield*` 处理效果（effects）
- 返回最终结果

如果在生成器中使用 `yield*` 处理的任何效果发生失败，则该生成器将停止并以该失败退出。

## 与 async/await 对比

如果您熟悉 `async`/`await`，您可能会注意到编写代码的流程类似。

让我们比较这两种方法：

### 使用 Effect.gen

```typescript
import { Effect } from "effect"

const addServiceCharge: (amount: number) => number = (amount: number) => amount + 1

const applyDiscount: (total: number, discountRate: number) => Effect.Effect<number, Error> = (
  total: number,
  discountRate: number
): Effect<number, Error> => 
  discountRate === 0
    ? Effect.fail(new Error("折扣率不能为零"))
    : Effect.succeed(total - (total * discountRate) / 100)

const fetchTransactionAmount: Effect.Effect<number, never, never> = Effect.promise(() => Promise.resolve(100))

const fetchDiscountRate: Effect.Effect<number, never, never> = Effect.promise(() => Promise.resolve(5))

export const program = Effect.gen(function* () {
  const transactionAmount = yield* fetchTransactionAmount
  const discountRate = yield* fetchDiscountRate
  const discountedAmount = yield* applyDiscount(transactionAmount, discountRate)
  const finalAmount = addServiceCharge(discountedAmount)
  return `最终收费金额：${finalAmount}`
})
```

### 使用 Async / Await

```typescript
const addServiceCharge: (amount: number) => number = (amount: number) => amount + 1

const applyDiscount: (total: number, discountRate: number) => Promise<number> = (
  total: number,
  discountRate: number
): Promise<number> => 
  discountRate === 0
    ? Promise.reject(new Error("折扣率不能为零"))
    : Promise.resolve(total - (total * discountRate) / 100)

const fetchTransactionAmount: Promise<number> = Promise.resolve(100)

const fetchDiscountRate: Promise<number> = Promise.resolve(5)

export const program = async function () {
  const transactionAmount = await fetchTransactionAmount
  const discountRate = await fetchDiscountRate
  const discountedAmount = await applyDiscount(transactionAmount, discountRate)
  const finalAmount = addServiceCharge(discountedAmount)
  return `最终收费金额：${finalAmount}`
}
```

虽然代码看起来相似，但这两个程序并不是完全相同的。我们并列比较的目的是突出它们在编写方式上的相似之处。

## 拥抱控制流

使用生成器函数与 `Effect.gen` 结合的一个显著优势是能够在生成器函数中使用标准的控制流结构。这些结构包括 `if`/`else`、`for`、`while` 以及其他分支和循环机制，增强了您在代码中表达复杂控制流逻辑的能力。

**示例**（使用控制流）

```typescript
import { Effect } from "effect"

const calculateTax: (amount: number, taxRate: number) => Effect.Effect<number, Error> = (
  amount: number,
  taxRate: number
): Effect<number, Error> => 
  taxRate > 0
    ? Effect.succeed((amount * taxRate) / 100)
    : Effect.fail(new Error("无效的税率"))

const program: Effect.Effect<void, Error, never> = Effect.gen(function* () {
  let i = 1
  
  while (true) {
    if (i === 10) {
      break // 当计数器达到 10 时退出循环
    } else {
      if (i % 2 === 0) {
        // 计算偶数的税
        yield* calculateTax(i, i)
      }
      i++
      continue
    }
  }
})

Effect.runPromise(program)
// 输出：2   4   6   8
```

## 如何抛出错误

`Effect.gen` API 允许您通过将失败的效果插入工作流来直接将错误处理集成到您的业务流程中。您可以使用 `Effect.fail` 引入错误，如下面的示例所示。

**示例**（在流程中引入错误）

```typescript
import { Effect, Console } from "effect"

const task1: Effect.Effect<void, never, never> = Console.log("task1...")

const task2: Effect.Effect<void, never, never> = Console.log("task2...")

const program: Effect.Effect<void, string, never> = Effect.gen(function* () {
  // 执行一些任务
  yield* task1
  yield* task2
  
  // 引入错误
  yield* Effect.fail("出错了！")
})

Effect.runPromise(program).catch(console.error)
// 输出：
// task1...
// task2...
// (FiberFailure) Error: 出错了！
```

## 短路的作用

生成器函数具有短路（short-circuiting）功能，这意味着一旦某个效果失败，生成器就会立即停止，不会执行后续的 yield 表达式。

**示例**（短路的体现）

```typescript
import { Effect } from "effect"

const program: Effect.Effect<void, string, never> = Effect.gen(function* () {
  Console.log("开始")
  
  yield* Effect.succeed(undefined)  // 这一行会执行
  Console.log("第二条")  // 执行
  
  yield* Effect.fail("错误！")  // 这一行会触发失败
  
  Console.log("第三条")  // 不会执行 - 短路!
  Console.log("第四条")    // 不会执行 - 短路！
  
  yield* Effect.succeed(undefined)
  Console.log("最后一条")   // 不会执行 - 短路！
})

Effect.runPromise(program).catch(console.error)
// 输出：
// 开始
// 第二条
// (FiberFailure) Error: 错误！
```

短路机制确保了错误能够立即传播，而不是继续执行剩余的效果。

## 传递 this

生成器函数中的 `this` 可以传递给效果，这允许您在生成器内部使用绑定上下文。

**示例**（在生成器中访问类上下文）

```typescript
import { Effect } from "effect"

class Calculator {
  private value: number = 0
  
  add(x: number): Effect.Effect<void, Error, never> {
    this.value += x
    return Effect.succeed(undefined)
  }
  
  getValue(): number {
    return this.value
  }
}

const calculator = new Calculator()

Effect.gen(function* () {
  yield* calculator.add(10)
  Console.log(`当前值：${calculator.getValue()}`)  // 输出：当前值：10
  yield* calculator.add(5)
  Console.log(`当前值：${calculator.getValue()}`)  // 输出：当前值：15
})

// 输出：
// 当前值：10
// 当前值：15
```

在使用 `Effect.gen` 时，如果生成器函数是某个类的实例方法，`this` 会自动传递到所有效果中，使您可以在生成器内访问实例数据和状态。

**生成器适配器用法（已弃用）**

你可能仍会遇到一些使用“适配器”的代码片段，通常通过 `_` 或 `$` 符号来标识。

在早期版本的 TypeScript 中，为了确保生成器内部的类型推导正确，必须使用生成器“适配器”函数。该适配器旨在辅助 TypeScript 类型系统与生成器函数之间的交互。

**示例**（使用适配器）

```typescript
import { Effect } from "effect"

const fetchTransactionAmount = Effect.promise(() => Promise.resolve(100))

// Older usage with an adapter for proper type inference
const programWithAdapter = Effect.gen(function* ($) {
  const transactionAmount = yield* $(fetchTransactionAmount)
})

// Current usage without an adapter
const program = Effect.gen(function* () {
  const transactionAmount = yield* fetchTransactionAmount
})
```

随着 TypeScript（v5.5+）的进步，类型推导已不再需要适配器。虽然为了向后兼容，它目前仍保留在代码库中，但预计将在 Effect 的下一个重大版本中被移除。
