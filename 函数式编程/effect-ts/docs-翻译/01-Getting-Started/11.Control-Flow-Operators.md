

# Control Flow Operators（控制流运算符）

尽管 JavaScript 提供了内置的控制流结构，但 Effect 还提供了对 Effect 应用程序有用的额外控制流函数。在本节中，我们将介绍不同的控制执行流的方式。

## if 表达式

在处理 Effect 值时，我们可以使用标准的 JavaScript if-then-else 语句：

**示例**（为无效权重返回 None）

这里我们使用 [Option](/docs/data-types/option/) 数据类型来表示不存在有效值的情况。

```ts twoslash
import { Effect, Option } from "effect"

// 验证重量并返回 Option 的函数
const validateWeightOption = (
  weight: number
): Effect.Effect<Option.Option<number>> => {
  if (weight >= 0) {
    // 如果重量有效，返回 Some
    return Effect.succeed(Option.some(weight))
  } else {
    // 如果重量无效，返回 None
    return Effect.succeed(Option.none())
  }
}
```

**示例**（为无效权重返回 Error）

你也可以使用错误通道来处理无效输入，当输入无效时返回错误：

```ts twoslash
import { Effect } from "effect"

// 验证重量或失败并抛出错误的函数
const validateWeightOrFail = (
  weight: number
): Effect.Effect<number, string> => {
  if (weight >= 0) {
    // 如果有效，返回重量
    return Effect.succeed(weight)
  } else {
    // 如果无效，失败并抛出错误
    return Effect.fail(`negative input: ${weight}`)
  }
}
```

## 条件运算符

### if

根据由 effectful 谓词评估的条件执行两个效应之一。

使用 `Effect.if` 运行两个效应中的一个，取决于谓词效应评估为 `true` 或 `false`。如果谓词为 `true`，则执行 `onTrue` 效应。如果为 `false`，则执行 `onFalse` 效应。

**示例**（模拟抛硬币）

在这个示例中，我们使用 `Random.nextBoolean` 模拟虚拟抛硬币，生成一个随机布尔值。如果值为 `true`，则 `onTrue` 效应记录 "Head"。如果值为 `false`，则 `onFalse` 效应记录 "Tail"。

```ts twoslash
import { Effect, Random, Console } from "effect"

const flipTheCoin = Effect.if(Random.nextBoolean, {
  onTrue: () => Console.log("Head"), // 如果谓词为 true 则运行
  onFalse: () => Console.log("Tail") // 如果谓词为 false 则运行
})

Effect.runFork(flipTheCoin)
```

### when

根据布尔条件有条件地执行效应。

`Effect.when` 允许你条件地执行效应，类似于使用 `if (condition)` 表达式，但具有处理效应的额外优势。如果条件为 `true`，则执行效应；否则，不执行任何操作。

将效应的结果包装在 `Option<A>` 中，以指示是否执行了该效应。如果条件为 `true`，将效应的结果包装在 `Some` 中。如果条件为 `false`，则结果为 `None`，表示效应被跳过。

**示例**（条件效应执行）

```ts twoslash
import { Effect, Option } from "effect"

const validateWeightOption = (
  weight: number
): Effect.Effect<Option.Option<number>> =>
  // 如果重量非负，条件地执行效应
  Effect.succeed(weight).pipe(Effect.when(() => weight >= 0))

// 使用有效重量运行
Effect.runPromise(validateWeightOption(100)).then(console.log)
/*
输出：
{
  _id: "Option",
  _tag: "Some",
  value: 100
}
*/

// 使用无效重量运行
Effect.runPromise(validateWeightOption(-5)).then(console.log)
/*
输出：
{
  _id: "Option",
  _tag: "None"
}
*/
```

在这个示例中，[Option](/docs/data-types/option/) 数据类型用于表示有效值的存在或不存在。如果条件评估为 `true`（在本例中，如果重量为非负），则执行效应并将其包装在 `Some` 中。否则，结果为 `None`。

### whenEffect

根据另一个效应的结果有条件地执行效应。

当确定是否执行效应的条件依赖于另一个产生布尔值的效应的结果时，使用 `Effect.whenEffect`。如果条件效应评估为 `true`，则执行指定的效应。如果评估为 `false`，则不执行任何效应。

将效应的结果包装在 `Option<A>` 中，以指示是否执行了该效应。如果条件为 `true`，将效应的结果包装在 `Some` 中。如果条件为 `false`，则结果为 `None`，表示效应被跳过。

**示例**（使用效应作为条件）

以下函数创建一个随机整数，但只有当随机生成的布尔值为 `true` 时才创建。

```ts twoslash
import { Effect, Random } from "effect"

const randomIntOption = Random.nextInt.pipe(
  Effect.whenEffect(Random.nextBoolean)
)

console.log(Effect.runSync(randomIntOption))
/*
示例输出：
{ _id: 'Option', _tag: 'Some', value: 8609104974198840 }
*/
```

### unless/unlessEffect

`Effect.unless` 和 `Effect.unlessEffect` 函数与 `when*` 函数类似，但等效于 `if (!condition) expression` 结构。

## Zipping | 拉链

### zip

将两个效应组合成一个效应，生成包含两个效应结果的元组。

`Effect.zip` 函数首先执行第一个效应（左侧），然后执行第二个效应（右侧）。两个效应都成功后，将其结果组合成元组。

**示例**（顺序组合两个效应）

```ts twoslash
import { Effect } from "effect"

const task1 = Effect.succeed(1).pipe(
  Effect.delay("200 millis"),
  Effect.tap(Effect.log("task1 done"))
)

const task2 = Effect.succeed("hello").pipe(
  Effect.delay("100 millis"),
  Effect.tap(Effect.log("task2 done"))
)

// 将两个效应组合在一起
//
//      ┌─── Effect<[number, string], never, never>
//      ▼
const program = Effect.zip(task1, task2)

Effect.runPromise(program).then(console.log)
/*
输出：
timestamp=... level=INFO fiber=#0 message="task1 done"
timestamp=... level=INFO fiber=#0 message="task2 done"
[ 1, 'hello' ]
*/
```

默认情况下，效应按顺序运行。要并行运行它们，使用 `{ concurrent: true }` 选项。

**示例**（并行组合两个效应）

```ts collapse={3-11} "{ concurrent: true }" "task2 done"
import { Effect } from "effect"

const task1 = Effect.succeed(1).pipe(
  Effect.delay("200 millis"),
  Effect.tap(Effect.log("task1 done"))
)

const task2 = Effect.succeed("hello").pipe(
  Effect.delay("100 millis"),
  Effect.tap(Effect.log("task2 done"))
)

// 使用并发选项并行运行两个效应
const program = Effect.zip(task1, task2, { concurrent: true })

Effect.runPromise(program).then(console.log)
/*
输出：
timestamp=... level=INFO fiber=#3 message="task2 done"
timestamp=... level=INFO fiber=#2 message="task1 done"
[ 1, 'hello' ]
*/
```

在这个并发版本中，两个效应并行运行。`task2` 先完成，但一旦两个任务完成，就可以记录和处理了。

### zipWith

顺序地组合两个效应，并对它们的结果应用函数以产生单个值。

`Effect.zipWith` 函数类似于 [Effect.zip](#zip)，但不是返回结果元组，而是对两个效应的结果应用提供的函数，将它们组合成单个值。

默认情况下，效应按顺序运行。要并行运行它们，使用 `{ concurrent: true }` 选项。

**示例**（使用自定义函数组合效应）

```ts twoslash
import { Effect } from "effect"

const task1 = Effect.succeed(1).pipe(
  Effect.delay("200 millis"),
  Effect.tap(Effect.log("task1 done"))
)
const task2 = Effect.succeed("hello").pipe(
  Effect.delay("100 millis"),
  Effect.tap(Effect.log("task2 done"))
)

//      ┌─── Effect<number, never, never>
//      ▼
const task3 = Effect.zipWith(
  task1,
  task2,
  // 将结果组合成单个值
  (number, string) => number + string.length
)

Effect.runPromise(task3).then(console.log)
/*
输出：
timestamp=... level=INFO fiber=#3 message="task1 done"
timestamp=... level=INFO fiber=#2 message="task2 done"
6
*/
```

## 循环

### loop

`Effect.loop` 函数允许你反复使用 `step` 函数更新状态，直到 `while` 函数定义的条件变为 `false`。它将中间状态收集到数组中并返回它们作为最终结果。

**语法**

```ts showLineNumbers=false
Effect.loop(initial, {
  while: (state) => boolean,
  step: (state) => state,
  body: (state) => Effect
})
```

该函数类似于 JavaScript 中的 `while` 循环，加了 effectful 计算：

```ts showLineNumbers=false
let state = initial
const result = []

while (options.while(state)) {
  result.push(options.body(state)) // 执行 effectful 操作
  state = options.step(state) // 更新状态
}

return result
```

**示例**（收集结果的循环）

```ts twoslash
import { Effect } from "effect"

// 循环 5 次，收集每次迭代的结果
const result = Effect.loop(
  // 初始状态
  1,
  {
    // 继续循环的条件
    while: (state) => state <= 5,
    // 状态更新函数
    step: (state) => state + 1,
    // 每次迭代执行的效应
    body: (state) => Effect.succeed(state)
  }
)

Effect.runPromise(result).then(console.log)
// 输出：[1, 2, 3, 4, 5]
```

在这个示例中，循环从状态 `1` 开始，并一直持续到状态超过 `5`。每个状态都增加 `1` 并收集到数组中，该数组成为最终结果。

#### 丢弃中间结果

当 `discard` 选项设置为 `true` 时，将丢弃每个 effectful 操作的结果，返回 `void` 而不是数组。

**示例**（丢弃结果的循环）

```ts twoslash "discard: true"
import { Effect, Console } from "effect"

const result = Effect.loop(
  // 初始状态
  1,
  {
    // 继续循环的条件
    while: (state) => state <= 5,
    // 状态更新函数
    step: (state) => state + 1,
    // 每次迭代执行的效应
    body: (state) => Console.log(`Currently at state ${state}`),
    // 丢弃中间结果
    discard: true
  }
)

Effect.runPromise(result).then(console.log)
/*
输出：
Currently at state 1
Currently at state 2
Currently at state 3
Currently at state 4
Currently at state 5
undefined
*/
```

在这个示例中，循环在每个迭代中执行一个副作用来记录当前索引，但它丢弃了所有中间结果。最终结果是 `undefined`。

### iterate

`Effect.iterate` 函数让你通过 effectful 操作反复更新状态。它在每次迭代中运行 `body` 效应来更新状态，只要 `while` 条件评估为 `true` 就继续。

**语法**

```ts showLineNumbers=false
Effect.iterate(initial, {
  while: (result) => boolean,
  body: (result) => Effect
})
```

该函数类似于 JavaScript 中的 `while` 循环，加了 effectful 计算：

```ts showLineNumbers=false
let result = initial

while (options.while(result)) {
  result = options.body(result)
}

return result
```

**示例**（Effectful 迭代）

```ts twoslash
import { Effect } from "effect"

const result = Effect.iterate(
  // 初始结果
  1,
  {
    // 继续迭代的条件
    while: (result) => result <= 5,
    // 改变结果的操作
    body: (result) => Effect.succeed(result + 1)
  }
)

Effect.runPromise(result).then(console.log)
// 输出：6
```

### forEach

对 `Iterable` 中的每个元素执行 effectful 操作。

`Effect.forEach` 函数对可迭代对象中的每个元素应用提供的操作，产生一个新效应，返回结果数组。如果任何效应失败，迭代立即停止（短路），并传播错误。

`concurrency` 选项控制并行执行多少操作。默认情况下，操作按顺序执行。

**示例**（将效应应用于可迭代元素）

```ts twoslash
import { Effect, Console } from "effect"

const result = Effect.forEach([1, 2, 3, 4, 5], (n, index) =>
  Console.log(`Currently at index ${index}`).pipe(Effect.as(n * 2))
)

Effect.runPromise(result).then(console.log)
/*
输出：
Currently at index 0
Currently at index 1
Currently at index 2
Currently at index 3
Currently at index 4
[ 2, 4, 6, 8, 10 ]
*/
```

在这个示例中，我们遍历数组 `[1, 2, 3, 4, 5]`，应用一个记录当前索引的效应。`Effect.as(n * 2)` 操作转换每个值，产生数组 `[2, 4, 6, 8, 10]`。最终输出是收集所有转换值的結果。

#### 丢弃结果

当 `discard` 选项设置为 `true` 时，将丢弃每个 effectful 操作的结果，返回 `void` 而不是数组。

**示例**（使用 `discard` 忽略结果）

```ts twoslash "{ discard: true }"
import { Effect, Console } from "effect"

// 应用效应但丢弃结果
const result = Effect.forEach(
  [1, 2, 3, 4, 5],
  (n, index) =>
    Console.log(`Currently at index ${index}`).pipe(Effect.as(n * 2)),
  { discard: true }
)

Effect.runPromise(result).then(console.log)
/*
输出：
Currently at index 0
Currently at index 1
Currently at index 2
Currently at index 3
Currently at index 4
undefined
*/
```

在这种情况下，效应仍然为每个元素运行，但结果被丢弃，因此最终输出是 `undefined`。

## 收集

### all

将多个效应组合成一个，根据输入结构返回结果。

当你需要运行多个效应并将它们的结果组合成单个输出时，使用 `Effect.all`。它支持元组、可迭代对象、结构和记录，使其对不同输入类型很有灵活。

如果任何效应失败，它将停止执行（短路）并传播错误。要改变这种行为，你可以使用 [`mode`](#the-mode-option) 选项，它允许所有效应运行并收集结果，返回 [Either](/docs/data-types/either/) 或 [Option](/docs/data-types/option/)。

你可以使用 [并发选项](/docs/concurrency/basic-concurrency/#concurrency-options) 控制执行顺序（例如，顺序还是并发）。

例如，如果输入是一个元组：

```ts showLineNumbers=false
//         ┌─── 效应元组
//         ▼
Effect.all([effect1, effect2, ...])
```

效应按顺序执行，结果是包含结果作为元组的新效应。元组中的结果与传递给 `Effect.all` 的效应的顺序匹配。

让我们探讨不同类型结构（元组、可迭代对象、对象和记录）的示例。

**示例**（元组中的组合效应）

```ts twoslash
import { Effect, Console } from "effect"

const tupleOfEffects = [
  Effect.succeed(42).pipe(Effect.tap(Console.log)),
  Effect.succeed("Hello").pipe(Effect.tap(Console.log))
] as const

//      ┌─── Effect<[number, string], never, never>
//      ▼
const resultsAsTuple = Effect.all(tupleOfEffects)

Effect.runPromise(resultsAsTuple).then(console.log)
/*
输出：
42
Hello
[ 42, 'Hello' ]
*/
```

**示例**（可迭代对象中的组合效应）

```ts twoslash
import { Effect, Console } from "effect"

const iterableOfEffects: Iterable<Effect.Effect<number>> = [1, 2, 3].map(
  (n) => Effect.succeed(n).pipe(Effect.tap(Console.log))
)

//      ┌─── Effect<number[], never, never>
//      ▼
const resultsAsArray = Effect.all(iterableOfEffects)

Effect.runPromise(resultsAsArray).then(console.log)
/*
输出：
1
2
3
[ 1, 2, 3 ]
*/
```

**示例**（结构中的组合效应）

```ts twoslash
import { Effect, Console } from "effect"

const structOfEffects = {
  a: Effect.succeed(42).pipe(Effect.tap(Console.log)),
  b: Effect.succeed("Hello").pipe(Effect.tap(Console.log))
}

//      ┌─── Effect<{ a: number; b: string; }, never, never>
//      ▼
const resultsAsStruct = Effect.all(structOfEffects)

Effect.runPromise(resultsAsStruct).then(console.log)
/*
输出：
42
Hello
{ a: 42, b: 'Hello' }
*/
```

**示例**（记录中的组合效应）

```ts twoslash
import { Effect, Console } from "effect"

const recordOfEffects: Record<string, Effect.Effect<number>> = {
  key1: Effect.succeed(1).pipe(Effect.tap(Console.log)),
  key2: Effect.succeed(2).pipe(Effect.tap(Console.log))
}

//      ┌─── Effect<{ [x: string]: number; }, never, never>
//      ▼
const resultsAsRecord = Effect.all(recordOfEffects)

Effect.runPromise(resultsAsRecord).then(console.log)
/*
输出：
1
2
{ key1: 1, key2: 2 }
*/
```

#### 短路行为

`Effect.all` 函数在它遇到的第一个错误时停止执行，这称为"短路"。如果集合中的任何效应失败，则剩余的效应将不运行，并且错误将传播。

**示例**（在第一次失败时退出）

```ts twoslash
import { Effect, Console } from "effect"

const program = Effect.all([
  Effect.succeed("Task1").pipe(Effect.tap(Console.log)),
  Effect.fail("Task2: Oh no!").pipe(Effect.tap(Console.log)),
  // 由于之前的失败，不会执行
  Effect.succeed("Task3").pipe(Effect.tap(Console.log))
])

Effect.runPromiseExit(program).then(console.log)
/*
输出：
Task1
{
  _id: 'Exit',
  _tag: 'Failure',
  cause: { _id: 'Cause', _tag: 'Fail', failure: 'Task2: Oh no!' }
}
*/
```

你可以使用 `mode` 选项覆盖这种行为。

#### `mode` 选项

`{ mode: "either" }` 选项改变 `Effect.all` 的行为，确保所有效应都会运行，即使有一些失败。不是在第一次失败时停止，而是此模式收集成功和失败，返回 `Either` 实例数组，其中每个结果都是 `Right`（成功）或 `Left`（失败）。

**示例**（使用 `mode: "either"` 收集结果）

```ts twoslash /{ mode: "either" }/
import { Effect, Console } from "effect"

const effects = [
  Effect.succeed("Task1").pipe(Effect.tap(Console.log)),
  Effect.fail("Task2: Oh no!").pipe(Effect.tap(Console.log)),
  Effect.succeed("Task3").pipe(Effect.tap(Console.log))
]

const program = Effect.all(effects, { mode: "either" })

Effect.runPromiseExit(program).then(console.log)
/*
输出：
Task1
Task3
{
  _id: 'Exit',
  _tag: 'Success',
  value: [
    { _id: 'Either', _tag: 'Right', right: 'Task1' },
    { _id: 'Either', _tag: 'Left', left: 'Task2: Oh no!' },
    { _id: 'Either', _tag: 'Right', right: 'Task3' }
  ]
}
*/
```

类似地，`{ mode: "validate" }` 选项使用 `Option` 来指示成功或失败。每个效应成功返回 `None`，失败返回 `Some` 带错误。

**示例**（使用 `mode: "validate"` 收集结果）

```ts twoslash /{ mode: "validate" }/
import { Effect, Console } from "effect"

const effects = [
  Effect.succeed("Task1").pipe(Effect.tap(Console.log)),
  Effect.fail("Task2: Oh no!").pipe(Effect.tap(Console.log)),
  Effect.succeed("Task3").pipe(Effect.tap(Console.log))
]

const program = Effect.all(effects, { mode: "validate" })

Effect.runPromiseExit(program).then((result) => console.log("%o", result))
/*
输出：
Task1
Task3
{
  _id: 'Exit',
  _tag: 'Failure',
  cause: {
    _id: 'Cause',
    _tag: 'Fail',
    failure: [
      { _id: 'Option', _tag: 'None' },
      { _id: 'Option', _tag: 'Some', value: 'Task2: Oh no!' },
      { _id: 'Option', _tag: 'None' }
    ]
  }
}
*/
```
