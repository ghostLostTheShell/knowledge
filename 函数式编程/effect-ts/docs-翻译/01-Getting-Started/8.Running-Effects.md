# 运行 Effects

要执行效果（effect），您可以使用 `Effect` 模块提供的众多 `run` 函数之一。

## 在程序的边缘运行 Effects

推荐的方法是将程序的大部分逻辑设计为 Effects，在程序的"边缘"处使用 `run*` 函数。这种方法允许更灵活地执行程序并构建复杂的效果。

## runSync

同步执行效果，立即运行并返回结果。

**示例**（同步日志记录）

```typescript
import { Effect } from "effect"

const program: Effect.Effect<number, never, never> = Effect.sync(() => {
  console.log("Hello, World!")  // 副作用
  return 42
})

const result: number = Effect.runSync(program)
// 输出：Hello, World!
console.log(result)
// 输出：42
```

使用 `Effect.runSync` 运行不会失败且不包含任何异步操作的效果。如果效果失败或涉及异步工作，它将抛出错误，并在失败或异步操作发生处停止执行。

**示例**（与失败或异步效果的错误用法）

```typescript
import { Effect } from "effect"

try {
  // 尝试运行会失败的效果
  Effect.runSync(Effect.fail("我的错误"))
} catch (e) {
  console.error(e)
}
// 输出：
// (FiberFailure) Error: 我的错误

try {
  // 尝试运行涉及异步工作的效果
  Effect.runSync(Effect.promise(() => Promise.resolve(1)))
} catch (e) {
  console.error(e)
}
// 输出：
// (FiberFailure) AsyncFiberException: Fiber #0 无法同步解析。这是由于对执行异步工作的效果使用 runSync 导致的
```

## runSyncExit

同步运行效果，并以 [Exit](/docs/data-types/exit/) 类型返回结果，该类型表示效果的结果（成功或失败）。

使用 `Effect.runSyncExit` 可以了解效果是成功还是失败（包括缺陷），而无需处理异步操作。

`Exit` 类型表示效果的结果：

- 如果效果成功，结果包装在 `Success` 中
- 如果失败，则提供包含 [Cause](/docs/data-types/cause/) 类型的失败信息

**示例**（以 Exit 处理结果）

```typescript
import { Effect } from "effect"

console.log(Effect.runSyncExit(Effect.succeed(1)))
// 输出：
// {
//   _id: "Exit",
//   _tag: "Success",
//   value: 1
// }

console.log(Effect.runSyncExit(Effect.fail("我的错误")))
// 输出：
// {
//   _id: "Exit",
//   _tag: "Failure",
//   cause: {
//     _id: "Cause",
//     _tag: "Fail",
//     failure: "我的错误"
//   }
// }
```

如果效果包含异步操作，`Effect.runSyncExit` 将返回带有 `Die` 原因的 `Failure`，表示效果无法同步解析。

**示例**（导致 Die 的异步操作）

```typescript
import { Effect } from "effect"

console.log(Effect.runSyncExit(Effect.promise(() => Promise.resolve(1))))
// 输出：
// {
//   _id: 'Exit',
//   _tag: 'Failure',
//   cause: {
//     _id: 'Cause',
//     _tag: 'Die',
//     defect: [Fiber #0 无法同步解析。这是由于对执行异步工作的效果使用 runSync 导致的] {
//       fiber: [FiberRuntime],
//       _tag: 'AsyncFiberException',
//       name: 'AsyncFiberException'
//     }
//   }
// }
```

## runPromise

执行效果并作为 `Promise` 返回结果。

使用 `Effect.runPromise` 当您需要执行效果并使用 `Promise` 语法处理结果时，通常用于与其他基于 Promise 的代码兼容。

**示例**（作为 Promsie 运行成功的效果）

```typescript
import { Effect } from "effect"

Effect.runPromise(Effect.succeed(1)).then(console.log)
// 输出：1
```

**示例**（作为被拒绝的 Promise 处理失败的效果）

```typescript
import { Effect } from "effect"

Effect.runPromise(Effect.fail("我的错误")).catch(console.error)
// 输出：
// (FiberFailure) Error: 我的错误
```

使用 `Effect.runPromise` 可以在基于 Promise 的系统中执行效果并使用其结果，例如在集成期望 Promise 结果的第三方库时。

## runPromiseExit

执行效果并作为 `Promise` 返回 [Exit](/docs/data-types/exit/) 类型。

使用 `Effect.runPromiseExit` 当您需要在 Promise 风格中处理 Effect 的 success/failure 结果，包括 Defect。

**示例**（作为 Promise 处理 Exit）

```typescript
import { Effect } from "effect"

Effect.runPromiseExit(Effect.succeed(1)).then(console.log)
// 输出：
// {
//   _id: "Exit",
//   _tag: "Success",
//   value: 1
// }

Effect.runPromiseExit(Effect.fail("我的错误")).then(console.log)
// 输出：
// {
//   _id: "Exit",
//   _tag: "Failure",
//   cause: {
//     _id: "Cause",
//     _tag: "Fail",
//     failure: "我的错误"
//   }
// }
```

## runFork

异步运行效果并在后台返回 [Fiber](/docs/concurrency/fibers/)（轻量级任务）。

使用 `Effect.runFork` 当您需要在后台运行效果，稍后使用 `Fiber` 的结果时使用。

**示例**（后台运行效果）

```typescript
import { Effect } from "effect"

const program = Effect.sync(() => {
  console.log("Hello, World!")
  return 42
})

const fiber = Effect.runFork(program)
// 输出：Hello, World!

// Fiber 可用于稍后检查完成状态或获取结果
console.log(fiber)
// 输出：Fiber #0
```

## 同步与异步效果对比

| 运行时函数 | 同步/异步 | 错误处理 | 使用场景 |
|-----------|----------|---------|---------|
| `runSync` | 同步 | 抛出异常 | 纯同步且不会失败的效果 |
| `runSyncExit` | 同步 | 返回 Exit 类型 | 需要同步处理成功/失败的场景 |
| `runPromise` | 异步 | Promise reject | 与其他 Promise 代码兼容 |
| `runPromiseExit` | 异步 | Promise resolve Exit | 异步场景下需要 Exit |
| `runFork` | 异步 | Fiber 可以失败或终止 | 后台任务、需要聚合多个效果 |

## 运行 Effects 的最佳实践

1. **在程序边缘运行**：将效果逻辑保持为纯 Effect 描述，在程序的"边缘"处（如 main 函数、API 端点、命令行工具）使用 run 函数

2. **根据同步/异步选择**：
   - 纯同步操作 → 使用 `runSync` 或 `runSyncExit`
   - 异步操作 → 使用 `runPromise`、`runPromiseExit` 或 `runFork`

3. **错误处理优先**：使用 `runSyncExit` 可以在不抛出异常的情况下处理失败效果

4. **避免在纯逻辑中混入运行**：保持函数式转换，将运行操作推迟到程序边缘

## Unicodeheatsheet

| 函数 | 返回类型 | 错误处理方式 |
|------|---------|-------------|
| `Effect.runSync` | `A` | 抛出异常 |
| `Effect.runSyncExit` | `Exit<A, E>` | 返回 Exit 类型 |
| `Effect.runPromise` | `Promise<A>` | Promise rejection |
| `Effect.runPromiseExit` | `Promise<Exit<A, E>>` | Promise resolve Exit |
| `Effect.runFork` | `Fiber<A, E>` | 后台 Fiber |
