层记忆化（Layer memoization）允许一个层在依赖图中被创建一次并多次使用。如果我们两次使用了同一个层：

```ts showLineNumbers=false "L1"
Layer.merge(Layer.provide(L2, L1), Layer.provide(L3, L1))
```

那么 `L1` 层将只会被分配一次。

<Aside type="caution" title="避免重复创建层">
  层是使用 **引用相等性 (reference equality)** 进行记忆化的。因此，如果你有一个通过调用函数（如 `f()`）创建的层，你应该 *只* 调用一次 `f` 并重用生成的层实例，以确保你始终使用的是同一个引用。
</Aside>

## 全局提供时的记忆化

Effect 应用程序的一个重要特性是：层在默认情况下是共享的。这意味着如果同一个层被使用了两次，并且我们是在全局范围内提供该层，那么该层将只会被分配一次。对于依赖图中的每一个层，在所有依赖它的层之间只存在一个共享实例。

**示例**

假设我们有三个服务 `A`、`B` 和 `C`。`B` 和 `C` 的实现都依赖于 `A` 服务：

```ts twoslash
import { Effect, Context, Layer } from "effect"

class A extends Context.Tag("A")<A, { readonly a: number }>() {}

class B extends Context.Tag("B")<B, { readonly b: string }>() {}

class C extends Context.Tag("C")<C, { readonly c: boolean }>() {}

const ALive = Layer.effect(
  A,
  Effect.succeed({ a: 5 }).pipe(
    Effect.tap(() => Effect.log("initialized"))
  )
)

const BLive = Layer.effect(
  B,
  Effect.gen(function* () {
    const { a } = yield* A
    return { b: String(a) }
  })
)

const CLive = Layer.effect(
  C,
  Effect.gen(function* () {
    const { a } = yield* A
    return { c: a > 0 }
  })
)

const program = Effect.gen(function* () {
  yield* B
  yield* C
})

// 虽然 BLive 和 CLive 都需要 ALive，但 ALive 只会实例化一次
const runnable = Effect.provide(
  program,
  Layer.merge(Layer.provide(BLive, ALive), Layer.provide(CLive, ALive))
)

Effect.runPromise(runnable)
/*
输出:
timestamp=... level=INFO fiber=#2 message=initialized
*/
```

尽管 `BLive` 和 `CLive` 层都需要 `ALive` 层，但 `ALive` 层仅被实例化了一次，并由 `BLive` 和 `CLive` 共享。

## 获取全新的版本

如果我们不想共享一个模块，我们应该通过 `Layer.fresh` 创建一个全新的、非共享的版本。

**示例**

```ts twoslash
import { Effect, Context, Layer } from "effect"

class A extends Context.Tag("A")<A, { readonly a: number }>() {}

class B extends Context.Tag("B")<B, { readonly b: string }>() {}

class C extends Context.Tag("C")<C, { readonly c: boolean }>() {}

const ALive = Layer.effect(
  A,
  Effect.succeed({ a: 5 }).pipe(
    Effect.tap(() => Effect.log("initialized"))
  )
)

const BLive = Layer.effect(
  B,
  Effect.gen(function* () {
    const { a } = yield* A
    return { b: String(a) }
  })
)

const CLive = Layer.effect(
  C,
  Effect.gen(function* () {
    const { a } = yield* A
    return { c: a > 0 }
  })
)

const program = Effect.gen(function* () {
  yield* B
  yield* C
})

const runnable = Effect.provide(
  program,
  Layer.merge(
    Layer.provide(BLive, Layer.fresh(ALive)),
    Layer.provide(CLive, Layer.fresh(ALive))
  )
)

Effect.runPromise(runnable)
/*
输出:
timestamp=... level=INFO fiber=#2 message=initialized
timestamp=... level=INFO fiber=#3 message=initialized
*/
```

## 局部提供时没有记忆化

如果我们不在全局范围内提供层，而是局部地提供它们，那么默认情况下该层不支持记忆化。

**示例**

在下面的示例中，我们在局部提供了两次 `ALive` 层，Effect 不会记忆化 `ALive` 层的构建过程。因此，它将被初始化两次：

```ts twoslash
import { Effect, Context, Layer } from "effect"

class A extends Context.Tag("A")<A, { readonly a: number }>() {}

const Alive = Layer.effect(
  A,
  Effect.succeed({ a: 5 }).pipe(
    Effect.tap(() => Effect.log("initialized"))
  )
)

const program = Effect.gen(function* () {
  // 局部提供
  yield* Effect.provide(A, Alive)
  yield* Effect.provide(A, Alive)
})

Effect.runPromise(program)
/*
输出:
timestamp=... level=INFO fiber=#0 message=initialized
timestamp=... level=INFO fiber=#0 message=initialized
*/
```

## 手动记忆化

我们可以使用 `Layer.memoize` 函数手动记忆化一个层。它将返回一个作用域化的 Effect（scoped effect），该 Effect 在执行时会返回该层的惰性计算结果。

**示例**

```ts twoslash
import { Effect, Context, Layer } from "effect"

class A extends Context.Tag("A")<A, { readonly a: number }>() {}

const ALive = Layer.effect(
  A,
  Effect.succeed({ a: 5 }).pipe(
    Effect.tap(() => Effect.log("initialized"))
  )
)

const program = Effect.scoped(
  Layer.memoize(ALive).pipe(
    Effect.andThen((memoized) =>
      Effect.gen(function* () {
        // 使用手动记忆化后的层
        yield* Effect.provide(A, memoized)
        yield* Effect.provide(A, memoized)
      })
    )
  )
)

Effect.runPromise(program)
/*
输出:
timestamp=... level=INFO fiber=#0 message=initialized
*/
```
