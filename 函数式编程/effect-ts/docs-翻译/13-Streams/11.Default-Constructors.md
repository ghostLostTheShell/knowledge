在处理数据结构时，以最小的努力创建符合模式的值是非常有帮助的。为此，Schema 模块为各种模式类型提供了默认构造函数，包括结构体、记录、过滤器和品牌类型。

**构造函数作用域**

与类型为 `Schema<A, I, R>` 的模式关联的默认构造函数专门作用于**解码后的类型（A）**，而不是编码后的类型（I）。

- **A（解码类型）**：这是解码和验证后产生的类型。构造函数创建此类型的值。
- **I（编码类型）**：这是解码原始输入时期望的类型。构造函数不直接接受此类型。

这种区别在处理转换数据的模式时非常重要。例如，如果一个模式将字符串解码为数字，默认构造函数将只接受数字，而不接受字符串。

默认构造函数是**不安全的**，意味着如果输入不符合模式，它们会抛出错误。如果您需要更安全的替代方案，可以考虑使用 `Schema.validateEither`，它会返回一个指示成功或失败的结果，而不是抛出错误。

**示例**（使用精炼默认构造函数）

```ts twoslash
import { Schema } from "effect"

const schema = Schema.NumberFromString.pipe(Schema.between(1, 10))

// 构造函数只接受数字
console.log(schema.make(5))
// 输出: 5

// 这将抛出错误，因为数字超出了有效范围
console.log(schema.make(20))
/*
抛出:
ParseError: between(1, 10)
└─ Predicate refinement failure
   └─ Expected a number between 1 and 10, actual 20
*/
```

## 结构体

结构体模式允许您定义具有特定字段和约束的对象。`make` 函数可用于创建结构体模式的实例。

**示例**（创建结构体实例）

```ts twoslash
import { Schema } from "effect"

const Struct = Schema.Struct({
  name: Schema.NonEmptyString
})

// 成功创建
Struct.make({ name: "a" })

// 这将抛出错误，因为名称为空
Struct.make({ name: "" })
/*
抛出
ParseError: { readonly name: NonEmptyString }
└─ ["name"]
   └─ NonEmptyString
      └─ Predicate refinement failure
         └─ Expected NonEmptyString, actual ""
*/
```

在某些情况下，您可能需要绕过验证。虽然在大多数场景中不推荐，但 `make` 提供了一个禁用验证的选项。

**示例**（绕过验证）

```ts twoslash
import { Schema } from "effect"

const Struct = Schema.Struct({
  name: Schema.NonEmptyString
})

// 实例化时绕过验证
Struct.make({ name: "" }, true)

// 或显式使用 `disableValidation` 选项
Struct.make({ name: "" }, { disableValidation: true })
```

## 记录

记录模式允许您定义键值映射，其中键和值必须满足特定条件。

**示例**（创建记录实例）

```ts twoslash
import { Schema } from "effect"

const Record = Schema.Record({
  key: Schema.String,
  value: Schema.NonEmptyString
})

// 成功创建
Record.make({ a: "a", b: "b" })

// 这将抛出错误，因为 'b' 是空字符串
Record.make({ a: "a", b: "" })
/*
抛出
ParseError: { readonly [x: string]: NonEmptyString }
└─ ["b"]
   └─ NonEmptyString
      └─ Predicate refinement failure
         └─ Expected NonEmptyString, actual ""
*/

// 绕过验证
Record.make({ a: "a", b: "" }, { disableValidation: true })
```

## 过滤器

过滤器允许您对单个值定义约束。

**示例**（使用过滤器强制执行范围）

```ts twoslash
import { Schema } from "effect"

const MyNumber = Schema.Number.pipe(Schema.between(1, 10))

// 成功创建
const n = MyNumber.make(5)

// 这将抛出错误，因为数字超出了有效范围
MyNumber.make(20)
/*
抛出
ParseError: a number between 1 and 10
└─ Predicate refinement failure
   └─ Expected a number between 1 and 10, actual 20
*/

// 绕过验证
MyNumber.make(20, { disableValidation: true })
```

## 品牌类型

品牌模式向值添加元数据以赋予其更具体的类型，同时仍保留其原始类型。

**示例**（创建品牌值）

```ts twoslash
import { Schema } from "effect"

const BrandedNumberSchema = Schema.Number.pipe(
  Schema.between(1, 10),
  Schema.brand("MyNumber")
)

// 成功创建
const n = BrandedNumberSchema.make(5)

// 这将抛出错误，因为数字超出了有效范围
BrandedNumberSchema.make(20)
/*
抛出
ParseError: a number between 1 and 10 & Brand<"MyNumber">
└─ Predicate refinement failure
   └─ Expected a number between 1 and 10 & Brand<"MyNumber">, actual 20
*/

// 绕过验证
BrandedNumberSchema.make(20, { disableValidation: true })
```

使用默认构造函数时，了解它们产生的值的类型是很有帮助的。

例如，在 `BrandedNumberSchema` 示例中，构造函数的返回类型是 `number & Brand<"MyNumber">`。这表示结果是带有额外品牌信息 `"MyNumber"` 的数字。

这种行为与过滤器示例形成对比，在过滤器示例中，返回类型只是 `number`。品牌化增加了额外的类型信息层，这可以帮助您更有效地识别和处理数据。

## 构造函数中的错误处理

默认构造函数被认为是“不安全的”，因为如果输入不符合模式，它们会抛出错误。此错误包含对出错内容的详细描述。默认构造函数的目的是提供一种直接的方式来创建有效值，例如用于测试或配置，其中无效输入预计是异常情况。

如果您需要“安全”的构造函数（不抛出错误，而是返回指示成功或失败的结果），您可以使用 `Schema.validateEither`。

**示例**（使用 Schema.validateEither 进行安全验证）

```ts twoslash
import { Schema } from "effect"

const schema = Schema.NumberFromString.pipe(Schema.between(1, 10))

// 创建一个安全的构造函数来验证未知输入
const safeMake = Schema.validateEither(schema)

// 有效输入返回 Right 值
console.log(safeMake(5))
/*
输出:
{ _id: 'Either', _tag: 'Right', right: 5 }
*/

// 无效输入返回带有详细错误信息的 Left 值
console.log(safeMake(20))
/*
输出:
{
  _id: 'Either',
  _tag: 'Left',
  left: {
    _id: 'ParseError',
    message: 'between(1, 10)\n' +
      '└─ Predicate refinement failure\n' +
      '   └─ Expected a number between 1 and 10, actual 20'
  }
}
*/

// 这将抛出错误，因为它是不安全的
schema.make(20)
/*
抛出:
ParseError: between(1, 10)
└─ Predicate refinement failure
   └─ Expected a number between 1 and 10, actual 20
*/
```

## 设置默认值

创建对象时，您可能希望为某些字段分配默认值以简化对象构造。`Schema.withConstructorDefault` 函数允许您处理默认值，使字段在默认构造函数中成为可选的。

**示例**（带有必需字段的结构体）

在此示例中，创建新实例时需要所有字段。

```ts twoslash
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.NonEmptyString,
  age: Schema.Number
})

// 必须提供 name 和 age
console.log(Person.make({ name: "John", age: 30 }))
/*
输出: { name: 'John', age: 30 }
*/
```

**示例**（带有默认值的结构体）

这里，`age` 字段是可选的，因为它有一个默认值 `0`。

```ts twoslash
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.NonEmptyString,
  age: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => 0)
  )
})

// age 字段是可选的，默认为 0
console.log(Person.make({ name: "John" }))
/*
输出:
{ name: 'John', age: 0 }
*/

console.log(Person.make({ name: "John", age: 30 }))
/*
输出:
{ name: 'John', age: 30 }
*/
```

## 嵌套结构体和浅层默认值

模式中的默认值是浅层的，这意味着在嵌套结构体中定义的默认值不会自动传播到顶层构造函数。

**示例**（嵌套结构体中的浅层默认值）

```ts twoslash
import { Schema } from "effect"

const Config = Schema.Struct({
  // 定义一个带有默认值的嵌套结构体
  web: Schema.Struct({
    application_url: Schema.String.pipe(
      Schema.propertySignature,
      Schema.withConstructorDefault(() => "http://localhost")
    ),
    application_port: Schema.Number
  })
})

// 这将导致类型错误，因为嵌套结构体中缺少 `application_url`
Config.make({ web: { application_port: 3000 } })
// Error ts(2741) ― 类型 '{ application_port: number; }' 中缺少属性 'application_url'，但在类型 '{ readonly application_url: string; readonly application_port: number; }' 中是必需的。
```

此行为发生是因为 Schema 接口不包含用于从嵌套结构体传递默认构造函数类型的类型参数。

为了解决这个限制，提取嵌套结构体的构造函数并将其直接应用于其字段。这确保了嵌套的默认值得到遵守。

**示例**（使用嵌套结构体构造函数）

```ts twoslash
import { Schema } from "effect"

const Config = Schema.Struct({
  web: Schema.Struct({
    application_url: Schema.String.pipe(
      Schema.propertySignature,
      Schema.withConstructorDefault(() => "http://localhost")
    ),
    application_port: Schema.Number
  })
})

// 提取嵌套结构体构造函数
const { web: Web } = Config.fields

// 使用嵌套结构体的构造函数
console.log(Config.make({ web: Web.make({ application_port: 3000 }) }))
/*
输出:
{
  web: {
    application_url: 'http://localhost',
    application_port: 3000
  }
}
*/
```

## 默认值的惰性求值

默认值是惰性求值的，这意味着每次调用构造函数时都会生成一个新的默认实例：

**示例**（默认值的惰性求值）

在此示例中，`timestamp` 字段为每个实例生成一个新值。

```ts twoslash
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.NonEmptyString,
  age: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => 0)
  ),
  timestamp: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => new Date().getTime())
  )
})

console.log(Person.make({ name: "name1" }))
/*
示例输出:
{ age: 0, timestamp: 1714232909221, name: 'name1' }
*/

console.log(Person.make({ name: "name2" }))
/*
示例输出:
{ age: 0, timestamp: 1714232909227, name: 'name2' }
*/
```

## 跨模式重用默认值

默认值也是“可移植的”，这意味着如果您在另一个模式中重用相同的属性签名，默认值会被携带过来：

**示例**（在另一个模式中重用默认值）

```ts twoslash
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.NonEmptyString,
  age: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => 0)
  ),
  timestamp: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => new Date().getTime())
  )
})

const AnotherSchema = Schema.Struct({
  foo: Schema.String,
  age: Person.fields.age
})

console.log(AnotherSchema.make({ foo: "bar" }))
/*
输出:
{ foo: 'bar', age: 0 }
*/
```

## 在类中使用默认值

在使用 Class API 时，默认值也可以应用，确保基于类的模式之间的一致性。

**示例**（类中的默认值）

```ts twoslash
import { Schema } from "effect"

class Person extends Schema.Class<Person>("Person")({
  name: Schema.NonEmptyString,
  age: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => 0)
  ),
  timestamp: Schema.Number.pipe(
    Schema.propertySignature,
    Schema.withConstructorDefault(() => new Date().getTime())
  )
}) {}

console.log(new Person({ name: "name1" }))
/*
示例输出:
Person { age: 0, timestamp: 1714400867208, name: 'name1' }
*/

console.log(new Person({ name: "name2" }))
/*
示例输出:
Person { age: 0, timestamp: 1714400867215, name: 'name2' }
*/
```
