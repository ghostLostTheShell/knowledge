`JSONSchema.make` 函数允许您从模式生成 JSON Schema。

**示例**（为结构体创建 JSON Schema）

以下示例定义了一个 `Person` 模式，其中包含 `name`（字符串）和 `age`（数字）属性。然后它生成相应的 JSON Schema。

```ts twoslash
import { JSONSchema, Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.String,
  age: Schema.Number
})

const jsonSchema = JSONSchema.make(Person)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "name",
    "age"
  ],
  "properties": {
    "name": {
      "type": "string"
    },
    "age": {
      "type": "number"
    }
  },
  "additionalProperties": false
}
*/
```

`JSONSchema.make` 函数旨在生成一个最优的 JSON Schema，表示解码阶段的输入部分。它通过从最嵌套的组件开始遍历模式来实现这一点，合并每个精炼，并在遇到**第一个转换**时停止。

**示例**（在 JSON Schema 中排除转换）

考虑修改 `age` 字段以同时包含精炼和转换。只有精炼会反映在 JSON Schema 中。

```ts twoslash
import { JSONSchema, Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.String,
  age: Schema.Number.pipe(
    // 包含在 JSON Schema 中的精炼
    Schema.int(),
    // 从 JSON Schema 中排除的转换
    Schema.clamp(1, 10)
  )
})

const jsonSchema = JSONSchema.make(Person)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "name",
    "age"
  ],
  "properties": {
    "name": {
      "type": "string"
    },
    "age": {
      "type": "integer",
      "description": "an integer",
      "title": "integer"
    }
  },
  "additionalProperties": false
}
*/
```

在这种情况下，JSON Schema 反映了整数精炼，但没有包含限制值的转换。

## 针对特定 JSON Schema 版本

默认情况下，`JSONSchema.make` 生成与 **Draft 07** 兼容的 JSON Schema。您可以通过传递一个带有 `target` 属性的选项对象来更改目标 schema 版本。支持的目标有：

- `"jsonSchema7"`（默认）- JSON Schema Draft 07
- `"jsonSchema2019-09"` - JSON Schema Draft 2019-09
- `"jsonSchema2020-12"` - JSON Schema Draft 2020-12
- `"openApi3.1"` - OpenAPI 3.1

更改目标会影响生成的输出。例如，元组模式在 Draft 07 中使用 `items` 和 `additionalItems`，而 Draft 2020-12 使用 `prefixItems` 和 `items`。

**示例**（为元组使用 JSON Schema 2020-12）

```ts twoslash
import { JSONSchema, Schema } from "effect"

const schema = Schema.Tuple(Schema.String, Schema.Number)

const jsonSchema = JSONSchema.make(schema, {
  target: "jsonSchema2020-12"
})

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "array",
  "minItems": 2,
  "prefixItems": [
    {
      "type": "string"
    },
    {
      "type": "number"
    }
  ],
  "items": false
}
*/
```

## 标识符注解

您可以向模式添加 `identifier` 注解以改善结构和可维护性。带注解的模式会包含在 JSON Schema 根目录的 `$defs` 对象中，并从那里被引用。

**示例**（使用标识符注解）

```ts twoslash
import { JSONSchema, Schema } from "effect"

const Name = Schema.String.annotations({ identifier: "Name" })

const Age = Schema.Number.annotations({ identifier: "Age" })

const Person = Schema.Struct({
  name: Name,
  age: Age
})

const jsonSchema = JSONSchema.make(Person)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$defs": {
    "Name": {
      "type": "string",
      "description": "a string",
      "title": "string"
    },
    "Age": {
      "type": "number",
      "description": "a number",
      "title": "number"
    }
  },
  "type": "object",
  "required": [
    "name",
    "age"
  ],
  "properties": {
    "name": {
      "$ref": "#/$defs/Name"
    },
    "age": {
      "$ref": "#/$defs/Age"
    }
  },
  "additionalProperties": false
}
*/
```

通过使用标识符注解，可以更轻松地重用和引用模式，尤其是在复杂的 JSON Schema 中。

## 标准 JSON Schema 注解

支持标准的 JSON Schema 注解，如 `title`、`description`、`default` 和 `examples`。这些注解允许您使用元数据丰富您的模式，这些元数据可以提高可读性并提供关于数据结构的额外信息。

**示例**（使用注解作为元数据）

```ts twoslash
import { JSONSchema, Schema } from "effect"

const schema = Schema.String.annotations({
  description: "my custom description",
  title: "my custom title",
  default: "",
  examples: ["a", "b"]
})

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "string",
  "description": "my custom description",
  "title": "my custom title",
  "examples": [
    "a",
    "b"
  ],
  "default": ""
}
*/
```

### 向结构体属性添加注解

为了提高 JSON Schema 的清晰度，建议将注解直接添加到属性签名而不是类型本身。这种方法在语义上更合适，因为它将描述性标题和其他元数据专门链接到它们描述的属性，而不是链接到泛型类型。

**示例**（带注解的结构体属性）

```ts twoslash
import { JSONSchema, Schema } from "effect"

const Person = Schema.Struct({
  firstName: Schema.propertySignature(Schema.String).annotations({
    title: "First name"
  }),
  lastName: Schema.propertySignature(Schema.String).annotations({
    title: "Last Name"
  })
})

const jsonSchema = JSONSchema.make(Person)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "firstName",
    "lastName"
  ],
  "properties": {
    "firstName": {
      "type": "string",
      "title": "First name"
    },
    "lastName": {
      "type": "string",
      "title": "Last Name"
    }
  },
  "additionalProperties": false
}
*/
```

## 递归和互递归模式

支持递归和互递归模式，但是对于这些类型的模式，**必须**使用 `identifier` 注解，以确保在生成的 JSON Schema 中有正确的引用和定义。

**示例**（带标识符注解的递归模式）

在此示例中，`Category` 模式引用自身，因此需要使用 `identifier` 注解来促进引用。

```ts twoslash
import { JSONSchema, Schema } from "effect"

// 定义表示类别结构的接口
interface Category {
  readonly name: string
  readonly categories: ReadonlyArray<Category>
}

// 定义一个带有必需标识符注解的递归模式
const Category = Schema.Struct({
  name: Schema.String,
  categories: Schema.Array(
    // 对 Category 模式的递归引用
    Schema.suspend((): Schema.Schema<Category> => Category)
  )
}).annotations({ identifier: "Category" })

const jsonSchema = JSONSchema.make(Category)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "$defs": {
    "Category": {
      "type": "object",
      "required": [
        "name",
        "categories"
      ],
      "properties": {
        "name": {
          "type": "string"
        },
        "categories": {
          "type": "array",
          "items": {
            "$ref": "#/$defs/Category"
          }
        }
      },
      "additionalProperties": false
    }
  },
  "$ref": "#/$defs/Category"
}
*/
```

## 自定义 JSON Schema 生成

在使用 JSON Schema 时，某些数据类型（如 `bigint`）缺乏直接表示，因为 JSON Schema 本身不支持它们。这种缺失通常会在生成模式时导致错误。

**示例**（因缺少注解而导致的错误）

尝试为 `bigint` 等不支持的类型生成 JSON Schema 将导致缺少注解的错误：

```ts twoslash
import { JSONSchema, Schema } from "effect"

const schema = Schema.Struct({
  a_bigint_field: Schema.BigIntFromSelf
})

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
抛出:
Error: Missing annotation
at path: ["a_bigint_field"]
details: Generating a JSON Schema for this schema requires a "jsonSchema" annotation
schema (BigIntKeyword): bigint
*/
```

为了解决这个问题，您可以使用自定义 `jsonSchema` 注解来增强模式，定义您打算如何在 JSON Schema 中表示此类类型：

**示例**（为不支持的类型使用自定义注解）

```ts twoslash
import { JSONSchema, Schema } from "effect"

const schema = Schema.Struct({
  // 为 `bigint` 类型添加自定义 JSON Schema 注解
  a_bigint_field: Schema.BigIntFromSelf.annotations({
    jsonSchema: {
      type: "some custom way to represent a bigint in JSON Schema"
    }
  })
})

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "a_bigint_field"
  ],
  "properties": {
    "a_bigint_field": {
      "type": "some custom way to represent a bigint in JSON Schema"
    }
  },
  "additionalProperties": false
}
*/
```

### 精炼

在定义精炼时（例如，通过 `Schema.filter` 函数），您可以包含一个 JSON Schema 注解来描述该精炼。此注解作为一个"片段"添加，成为生成的 JSON Schema 的一部分。如果一个模式包含多个精炼，它们各自的注解会被合并到输出中。

**示例**（使用带有合并注解的精炼）

```ts twoslash
import { JSONSchema, Schema } from "effect"

// 定义一个带有正数精炼的模式
const Positive = Schema.Number.pipe(
  Schema.filter((n) => n > 0, {
    jsonSchema: { minimum: 0 }
  })
)

// 为模式添加上限精炼
const schema = Positive.pipe(
  Schema.filter((n) => n <= 10, {
    jsonSchema: { maximum: 10 }
  })
)

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "number",
  "minimum": 0,
  "maximum": 10
}
*/
```

`jsonSchema` 注解被定义为一个泛型对象，允许它表示非标准扩展。这种灵活性将强制执行类型约束的责任留给了用户。

如果您更喜欢严格的类型执行或需要支持非标准扩展，您可以在对象字面量上引入 `satisfies` 约束。此约束应与您选择的类型库结合使用。

**示例**（确保类型正确性）

在以下示例中，我们使用了 `@types/json-schema` 包来为 JSON Schema 提供 TypeScript 定义。这种方法不仅确保了类型正确性，还能在 IDE 中启用自动补全建议。

```ts twoslash
import { JSONSchema, Schema } from "effect"
import type { JSONSchema7 } from "json-schema"

const Positive = Schema.Number.pipe(
  Schema.filter((n) => n > 0, {
    jsonSchema: { minimum: 0 } // 泛型对象，无类型强制
  })
)

const schema = Positive.pipe(
  Schema.filter((n) => n <= 10, {
    jsonSchema: { maximum: 10 } satisfies JSONSchema7 // 强制执行类型约束
  })
)

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "number",
  "minimum": 0,
  "maximum": 10
}
*/
```

对于除精炼之外的模式类型，您可以通过提供自定义的 `jsonSchema` 注解来覆盖默认生成的 JSON Schema。此注解的内容将替换系统生成的模式。

**示例**（为结构体自定义注解）

```ts twoslash
import { JSONSchema, Schema } from "effect"

// 定义一个带有自定义 JSON Schema 注解的结构体
const schema = Schema.Struct({ foo: Schema.String }).annotations({
  jsonSchema: { type: "object" }
})

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object"
}
默认会是:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "foo"
  ],
  "properties": {
    "foo": {
      "type": "string"
    }
  },
  "additionalProperties": false
}
*/
```

## 使用 Schema.parseJson 进行专门的 JSON Schema 生成

`Schema.parseJson` 函数为 JSON Schema 生成提供了一种独特的方法。它不是默认为纯字符串的模式（表示转换的"源"侧），而是根据参数中提供的结构生成模式。

此行为确保生成的 JSON Schema 反映了解析后数据的预期结构，而不是原始的 JSON 输入。

**示例**（为解析后的对象生成 JSON Schema）

```ts twoslash
import { JSONSchema, Schema } from "effect"

// 定义一个将 JSON 字符串解析为结构化对象的模式
const schema = Schema.parseJson(
  Schema.Struct({
    // 嵌套解析：JSON 字符串转换为数字
    a: Schema.parseJson(Schema.NumberFromString)
  })
)

const jsonSchema = JSONSchema.make(schema)

console.log(JSON.stringify(jsonSchema, null, 2))
/*
输出:
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": [
    "a"
  ],
  "properties": {
    "a": {
      "type": "string",
      "contentMediaType": "application/json"
    }
  },
  "additionalProperties": false
}
*/
```
