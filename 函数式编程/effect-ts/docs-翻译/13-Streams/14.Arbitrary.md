`Arbitrary.make` 函数允许创建与特定 `Schema<A, I, R>` 对齐的随机值。此函数返回来自 [fast-check](https://github.com/dubzzz/fast-check) 库的 `Arbitrary<A>`，这对于生成符合定义模式约束的随机测试数据特别有用。

**示例**（为模式生成任意数据）

```ts twoslash
import { Arbitrary, FastCheck, Schema } from "effect"

// 定义一个带有约束的 Person 模式
const Person = Schema.Struct({
  name: Schema.NonEmptyString,
  age: Schema.Int.pipe(Schema.between(1, 80))
})

// 基于模式创建 Arbitrary
const arb = Arbitrary.make(Person)

// 从 Arbitrary 生成随机样本
console.log(FastCheck.sample(arb, 2))
/*
示例输出:
[ { name: 'q r', age: 3 }, { name: '&|', age: 6 } ]
*/
```

为了使输出更真实，请参阅[自定义 Arbitrary 数据生成](#customizing-arbitrary-data-generation)部分。

<Aside type="tip" title="访问 FastCheck API">
  通过 `FastCheck` 导出可以访问 `fast-check` 的全部 API，允许在项目中直接使用其所有功能。
</Aside>

## 过滤器

在生成随机值时，`Arbitrary` 尝试遵循模式的约束。它使用最合适的 `fast-check` 原语，如果原语支持，则应用约束。

例如，如果您将 `age` 属性定义为：

```ts showLineNumbers=false
Schema.Int.pipe(Schema.between(1, 80))
```

任意值生成将使用：

```ts showLineNumbers=false
FastCheck.integer({ min: 1, max: 80 })
```

以生成该范围内的值。

<Aside type="note" title="避免过滤器中的冲突">
  当使用多个过滤器时，请注意，冲突的过滤器可能会导致任意数据生成期间挂起。当约束使得生成有效值变得困难或不可能时，就会发生这种情况。

  有关缓解这些问题的指导，请参考[此讨论](https://github.com/dubzzz/fast-check/discussions/4659)。
</Aside>

### 模式

要为必须匹配特定模式的字符串生成高效的任意值，请使用 `Schema.pattern` 过滤器，而不是编写自定义过滤器：

**示例**（使用 `Schema.pattern` 处理模式约束）

```ts twoslash
import { Schema } from "effect"

// ❌ 不使用 Schema.pattern（效率较低）
const Bad = Schema.String.pipe(Schema.filter((s) => /^[a-z]+$/.test(s)))

// ✅ 使用 Schema.pattern（效率更高）
const Good = Schema.String.pipe(Schema.pattern(/^[a-z]+$/))
```

通过使用 `Schema.pattern`，任意值生成将依赖于 `FastCheck.stringMatching(regexp)`，这更高效，并且与定义的模式直接对齐。

当使用多个模式时，它们会被组合成一个联合。例如：

```ts
(?:${pattern1})|(?:${pattern2})
```

这种方法确保了在使用 `FastCheck.stringMatching` 时，所有模式都有均等的机会生成值。

## 转换和 Arbitrary 生成

在生成任意数据时，理解如何在模式中处理转换和过滤器非常重要：

<Aside type="caution" title="过滤器被忽略">
  在转换链中最后一个转换之前应用的过滤器在生成任意数据时不会被考虑。
</Aside>

**示例**（过滤器和转换）

```ts twoslash
import { Arbitrary, FastCheck, Schema } from "effect"

// 在转换之前应用过滤器的模式
const schema1 = Schema.compose(Schema.NonEmptyString, Schema.Trim).pipe(
  Schema.maxLength(500)
)

// 由于忽略了 NonEmpty 过滤器，可能会产生空字符串
console.log(FastCheck.sample(Arbitrary.make(schema1), 2))
/*
示例输出:
[ '', '"Ry' ]
*/

// 在转换之后应用过滤器的模式
const schema2 = Schema.Trim.pipe(
  Schema.nonEmptyString(),
  Schema.maxLength(500)
)

// 遵守所有过滤器，避免空字符串
console.log(FastCheck.sample(Arbitrary.make(schema2), 2))
/*
示例输出:
[ ']H+MPXgZKz', 'SNS|waP~\\' ]
*/
```

**解释：**

- `schema1`：考虑了 `Schema.maxLength(500)`，因为它是在 `Schema.Trim` 转换之后应用的，但忽略了 `Schema.NonEmptyString`，因为它在转换之前。
- `schema2`：完全遵守所有过滤器，因为它们正确地排序在转换之后，防止生成不需要的数据。

### 最佳实践

为了确保一致且有效的任意数据生成，请遵循以下准则：

1. **首先应用过滤器**：为初始类型（`I`）定义过滤器。
2. **应用转换**：添加转换以转换数据。
3. **应用最终过滤器**：为转换后的类型（`A`）使用过滤器。

这种设置确保了数据处理的每个阶段都是精确且定义良好的。

**示例**（避免混合过滤器和转换）

避免随意组合转换和过滤器：

```ts twoslash
import { Schema } from "effect"

// 不太理想的方法：混合转换和过滤器
const problematic = Schema.compose(Schema.Lowercase, Schema.Trim)
```

通过将转换步骤与过滤器应用分开，采用结构化的方法：

**示例**（推荐的结构化方法）

```ts twoslash
import { Schema } from "effect"

// 推荐：分离转换和过滤器
const improved = Schema.transform(
  Schema.String,
  Schema.String.pipe(Schema.trimmed(), Schema.lowercased()),
  {
    strict: true,
    decode: (s) => s.trim().toLowerCase(),
    encode: (s) => s
  }
)
```

## 自定义 Arbitrary 数据生成

您可以使用模式定义中的 `arbitrary` 注解来自定义任意数据的生成方式。

**示例**（自定义 Arbitrary 生成器）

```ts twoslash
import { Arbitrary, FastCheck, Schema } from "effect"

const Name = Schema.NonEmptyString.annotations({
  arbitrary: () => (fc) =>
    fc.constantFrom("Alice Johnson", "Dante Howell", "Marta Reyes")
})

const Age = Schema.Int.pipe(Schema.between(1, 80))

const Person = Schema.Struct({
  name: Name,
  age: Age
})

const arb = Arbitrary.make(Person)

console.log(FastCheck.sample(arb, 2))
/*
示例输出:
[ { name: 'Dante Howell', age: 6 }, { name: 'Marta Reyes', age: 53 } ]
*/
```

该注解允许访问 fast-check 库（`fc`）的完整导出。这种设置使您能够返回一个精确生成所需数据类型的 `Arbitrary`。

### 与假数据生成器集成

当使用像 [@faker-js/faker](https://www.npmjs.com/package/@faker-js/faker) 这样的模拟库时，您可以将它们与 `fast-check` 结合，为测试目的生成逼真的数据。

**示例**（与 Faker 集成）

```ts twoslash
import { Arbitrary, FastCheck, Schema } from "effect"
import { faker } from "@faker-js/faker"

const Name = Schema.NonEmptyString.annotations({
  arbitrary: () => (fc) =>
    fc.constant(null).map(() => {
      // 每次对任意值进行采样时，faker 都会生成一个新名称
      return faker.person.fullName()
    })
})

const Age = Schema.Int.pipe(Schema.between(1, 80))

const Person = Schema.Struct({
  name: Name,
  age: Age
})

const arb = Arbitrary.make(Person)

console.log(FastCheck.sample(arb, 2))
/*
示例输出:
[
  { name: 'Henry Dietrich', age: 68 },
  { name: 'Lucas Haag', age: 52 }
]
*/
```
