有时，您可能希望基于现有模式创建一个新模式，专门关注其 `Type` 或 `Encoded` 方面。Schema 模块提供了几个函数来实现这一点。

## typeSchema

`Schema.typeSchema` 函数用于提取模式的 `Type` 部分，从而创建一个新模式，该模式仅保留原始模式中的类型特定属性。这排除了应用于原始模式的任何初始编码或转换逻辑。

**函数签名**

```ts showLineNumbers=false
declare const typeSchema: <A, I, R>(schema: Schema<A, I, R>) => Schema<A>
```

**示例**（仅提取类型特定属性）

```ts twoslash
import { Schema } from "effect"

const Original = Schema.Struct({
  quantity: Schema.NumberFromString.pipe(Schema.greaterThanOrEqualTo(2))
})

// 这创建一个模式，其中 'quantity' 被定义为一个数字，
// 必须大于或等于 2。
const TypeSchema = Schema.typeSchema(Original)

// TypeSchema 等同于：
const TypeSchema2 = Schema.Struct({
  quantity: Schema.Number.pipe(Schema.greaterThanOrEqualTo(2))
})
```

## encodedSchema

`Schema.encodedSchema` 函数使您能够提取模式的 `Encoded` 部分，创建一个与原始属性匹配的新模式，但**省略任何应用于模式的精炼或转换**。

**函数签名**

```ts showLineNumbers=false
declare const encodedSchema: <A, I, R>(
  schema: Schema<A, I, R>
) => Schema<I>
```

**示例**（仅提取编码属性）

```ts twoslash
import { Schema } from "effect"

const Original = Schema.Struct({
  quantity: Schema.String.pipe(Schema.minLength(3))
})

// 这创建一个模式，其中 'quantity' 只是一个字符串，
// 忽略 minLength 精炼。
const Encoded = Schema.encodedSchema(Original)

// Encoded 等同于：
const Encoded2 = Schema.Struct({
  quantity: Schema.String
})
```

## encodedBoundSchema

`Schema.encodedBoundSchema` 函数类似于 `Schema.encodedSchema`，但保留原始模式中第一个转换点之前的精炼。

**函数签名**

```ts showLineNumbers=false
declare const encodedBoundSchema: <A, I, R>(
  schema: Schema<A, I, R>
) => Schema<I>
```

此上下文中“bound”一词指的是在提取模式的编码形式时保留精炼的边界。它本质上标记了在应用任何转换之前保持初始验证和结构的限制。

**示例**（仅保留初始精炼）

```ts twoslash
import { Schema } from "effect"

const Original = Schema.Struct({
  foo: Schema.String.pipe(
    Schema.minLength(3),
    Schema.compose(Schema.Trim)
  )
})

// EncodedBoundSchema 模式保留 minLength(3) 精炼，
// 确保字符串长度条件得到强制执行，
// 但省略 Schema.Trim 转换。
const EncodedBoundSchema = Schema.encodedBoundSchema(Original)

// EncodedBoundSchema 等同于：
const EncodedBoundSchema2 = Schema.Struct({
  foo: Schema.String.pipe(Schema.minLength(3))
})
```
