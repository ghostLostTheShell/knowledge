`Schema.equivalence` 函数允许您根据模式定义生成一个 [Equivalence](/docs/schema/equivalence/)。该函数旨在根据模式中定义的规则来比较数据结构的等价性。

**示例**（比较结构体的等价性）

```ts twoslash
import { Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.String,
  age: Schema.Number
})

// 基于模式生成等价性函数
const PersonEquivalence = Schema.equivalence(Person)

const john = { name: "John", age: 23 }
const alice = { name: "Alice", age: 30 }

// 使用等价性函数来比较对象

console.log(PersonEquivalence(john, { name: "John", age: 23 }))
// 输出: true

console.log(PersonEquivalence(john, alice))
// 输出: false
```

## Any、Unknown 和 Object 的等价性

当处理以下模式时：

- `Schema.Any`
- `Schema.Unknown`
- `Schema.Object`
- `Schema.Struct({})`（表示宽泛的 `{}` TypeScript 类型）

最合理的等价形式是使用 [Equal](/docs/trait/equal/) 模块中的 `Equal.equals`，它默认使用引用相等性（`===`）。这是因为这些类型几乎可以包含任何类型的值。

**示例**（使用引用相等性比较空对象）

```ts twoslash
import { Schema } from "effect"

const schema = Schema.Struct({})

const input1 = {}
const input2 = {}

console.log(Schema.equivalence(schema)(input1, input2))
// 输出: false（因为它们是不同的引用）
```

## 自定义等价性生成

您可以通过在模式定义中提供一个 `equivalence` 注解来自定义等价性逻辑。

`equivalence` 注解接受任何提供的类型参数（`typeParameters`）和两个用于比较的值，并根据所需的等价条件返回一个布尔值。

**示例**（为字符串自定义等价性）

```ts twoslash
import { Schema } from "effect"

// 定义一个带有自定义等价性注解的模式
const schema = Schema.String.annotations({
  equivalence: (/**typeParameters**/) => (s1, s2) =>
    // 自定义规则：只比较字符串的第一个字符
    s1.charAt(0) === s2.charAt(0)
})

// 生成等价性函数
const customEquivalence = Schema.equivalence(schema)

// 使用自定义等价性函数
console.log(customEquivalence("aaa", "abb"))
// 输出: true（两者都以 'a' 开头）

console.log(customEquivalence("aaa", "bba"))
// 输出: false（字符串以不同的字符开头）
```
