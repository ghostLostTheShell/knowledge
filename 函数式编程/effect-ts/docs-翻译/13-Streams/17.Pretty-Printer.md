**Schema 到美化打印器**

`Pretty.make` 函数用于创建美化打印器，该打印器根据模式生成值的格式化字符串表示。

**示例**（为结构体模式创建美化打印器）

```ts twoslash
import { Pretty, Schema } from "effect"

const Person = Schema.Struct({
  name: Schema.String,
  age: Schema.Number
})

// 为模式创建美化打印器
const PersonPretty = Pretty.make(Person)

// 格式化并打印一个 Person 对象
console.log(PersonPretty({ name: "Alice", age: 30 }))
/*
输出:
'{ "name": "Alice", "age": 30 }'
*/
```

**自定义美化打印器生成**

您可以通过在模式定义中使用 `pretty` 注解来自定义美化打印器格式化输出的方式。

`pretty` 注解接受任何提供的类型参数（`typeParameters`），并将值格式化为字符串。

**示例**（为数字自定义美化打印器）

```ts twoslash
import { Pretty, Schema } from "effect"

// 定义一个带有自定义 pretty 注解的模式
const schema = Schema.Number.annotations({
  pretty: (/**typeParameters**/) => (value) => `my format: ${value}`
})

// 创建美化打印器
const customPrettyPrinter = Pretty.make(schema)

// 格式化并打印一个值
console.log(customPrettyPrinter(1))
// 输出: "my format: 1"
```
