# 

**工具**

* mitmproxy

## 原理

正常情况：浏览器 <-> bing服务器。浏览器信任bing的证书（由权威 CA 签名）。

MITM 情况：浏览器 <-> 中间人 <-> 百度服务器。
    
中间人要想解密数据，必须假装自己是bing。中间人自己生成一张“百度的证书”发给浏览器。浏览器一看：“这张证书不是权威 CA 签名的，是野鸡证书！” -> 报错并断开连接。

破解方法：你手动把中间人的**“根证书（Root CA）”**安装到客户端（电脑/手机）的受信任列表中。这样，由中间人签发的任何伪造证书，客户端都会无条件信任。

---

## 实操步骤

#### 第一步：搭建中间人代理服务器
你需要一台运行代理软件的设备（通常就是你的电脑）。

1.  **安装工具**：
    ```bash
    pip install mitmproxy
    ```
2.  **启动服务**：
    在终端输入 `mitmweb`。
    *   它会监听 `8080` 端口作为代理服务器。
    *   它会自动生成一个专属的 CA 根证书（在安装目录或 `~/.mitmproxy/` 下）。

#### 第二步：将流量引导到中间人（截流）
你需要让被攻击者（或者被调试的设备）的网络流量流经你的电脑。

*   **场景 A：抓本机流量**
    将系统网络代理设置为 `127.0.0.1:8080`。

*   **场景 B：抓手机流量（最常见）**
    1.  确保手机和电脑在**同一个 Wi-Fi** 下。
    2.  查看电脑的局域网 IP（例如 `192.168.1.5`）。
    3.  在手机 Wi-Fi 设置中，开启“手动代理”，填入 IP `192.168.1.5`，端口 `8080`。
*   **linux**

    ```sh
    export http_proxy=http://127.0.0.1:8080
    export https_proxy=http://127.0.0.1:8080
    export all_proxy=http://127.0.0.1:8080
    ```
  

#### 第三步：欺骗客户端信任（安装证书）
这是最关键的一步。

1.  **下载证书**：
    手机/电脑连上代理后，打开浏览器访问 **`mitm.it`**。这是 Mitmproxy 内置的一个特殊域名，专门用于分发证书。
2.  **安装证书**：
    *   **Android**: 下载 `.crt` 文件 -> 设置 -> 安全 -> 加密与凭据 -> 安装证书 -> CA 证书 -> 选择文件 -> 信任。
    *   **iOS**: 下载 Profile -> 设置 -> 已下载的描述文件 -> 安装。
    *   **iOS (额外步骤)**: 设置 -> 通用 -> 关于本机 -> 证书信任设置 -> 开启 Mitmproxy 的开关。
    *   **Windows**: 双击安装 -> 放入“受信任的根证书颁发机构”。
    *   **debain**: [文档](./https中间人代理.md)

#### 第四步：完成劫持与数据解密
一旦证书安装并信任完成：
1.  客户端发起 HTTPS 请求（例如访问 `https://www.google.com`）。
2.  Mitmproxy 拦截请求，**动态生成**一张 `www.google.com` 的伪造证书。
3.  客户端验证证书 -> 发现是由刚才安装的“信任根证书”签发的 -> **验证通过**。
4.  建立连接。Mitmproxy 拿到明文数据，展示给你看，然后再加密发给真正的 Google 服务器。
