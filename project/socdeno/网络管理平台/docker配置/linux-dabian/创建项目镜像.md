#

## 创建系统

1. 拉取系统镜像
  
    ```bash
    docker pull debian

    ##查看拉取的镜像信息

    docker images
    ```

2. 根据拉取系统镜像创建容器,并创建一个基础镜像

    这个镜像仅仅包含基础组件，方便扩展

    ```bash
    docker run -it debian /bin/bash
    #创建容器，并启动容器
    #docker create --name net-manage debian


    #修改源

    # 添加 resis
    apt-get install redis-server

    # 启动 resis

    redis-server &

    #添加jdk

    # 切换到属主主机
    curl -L https://download.java.net/openjdk/jdk14/ri/openjdk-14+36_linux-x64_bin.tar.gz -o ./openjdk-14+36_linux-x64_bin.tar.gz

    tar -xzvf openjdk-14+36_linux-x64_bin.tar.gz 

    # 复制到容器
    #查看容器ID
    docker ps a

    docker cp jdk-14 [容器id]:/usr/


    # 添加mariadb
    
    # 安装相关依赖
    apt install libncurses5 libaio-dev

    # 
    curl -L https://mirrors.nju.edu.cn/mariadb//mariadb-10.6.4/bintar-linux-systemd-x86_64/mariadb-10.6.4-linux-systemd-x86_64.tar.gz -o ./mariadb-10.6.4-linux-systemd-x86_64.tar.gz

    tar -xzvf mariadb-10.6.4-linux-systemd-x86_64.tar.gz

    # 根据容器创建基础组件的镜像

    docker commit -a chenjunjie -m '网络管理平台基础组件' e2f2de4a0524 inmp_base:v1 
    ```

    # 添加 emqx

    ```bash 
    wget https://www.emqx.com/en/downloads/broker/v4.3-rc.5/emqx-debian10-4.3-rc.5-amd64.zip

    unzip emqx-debian10-4.3-rc.5-amd64.zip

    docker cp ./emqx aff6ad29419a:/usr/

    ```

3. 初始化服务

    根据`基础镜像`创建服务镜像

    ```bash
    # 创建数据卷
    docker volume inms

    #  创建容器
    docker create --name inms_test -p 80:80 -p 3306:3306 -p 1883:1883 -p 162:162/udp -p 6379:6379 -v inms:/usr/inms -it inmp_base:v2 /bin/bash
    
    #初始化数据库

    /usr/mariadb/scripts/mariadb-install-db  --user=root --basedir=/usr/mariadb/ --datadir=/usr/inms/db

    # 创建数据库启动配置文件
    #[mysqld]
    #datadir=/usr/mariadb/data
    #port=3306
    #innodb_buffer_pool_size=1723M
    #character-set-server=utf8
    #

    # 开启数据库服务
    ./bin/mysqld --defaults-file=/usr/mariadb/data/my.ini --user=root

    
    ```

    



4.创建服务启动脚本

  ```bash /bin/start-server
  #/bin/bash

  emqx start 1> /tmp/emqx-info.log  2>/tmp/tmqx-err.log &

  redis-server  1> /tmp/redis-info.log  2>/tmp/redis-err.log &

  #mariadbd-safe --defaults-file=/usr/inms/db/my.ini --user=root 1> /tmp/db-info.log  2>/tmp/db-err.log &
  ```

5. 创建服务及启动

  ```bash

   docker create --name inms_test -p 80:80 -p 3306:3306 -p 1883:1883 -p 162:162/udp -p 6379:6379 -v inms:/usr/inms -it inmp_base:v2 /bin/start-sever

   docker start [容器id]

   docker exec -it [容器id] /bin/bash
  ```

## 可能会用到的命令

  - docker exec -it [容器id] /bin/bash

    执行容器的命令

  - docker commit [容器id] [镜像名称]

    根据容器创建新的镜像


  - docker rm -f [容器id]

    删除容器

  - docker rmi [image id]

    根据镜像id删除镜像

  - docker volume create [数据卷名称]

    创建数据卷

  - docker volume ls 

    查看数据卷

  - docker volume inspect [数据卷名称]

    查看数据卷信息
