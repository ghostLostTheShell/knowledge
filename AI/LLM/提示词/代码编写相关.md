## 🧠 一、基础认知

LLM 写代码 ≠ 直接「让它输出代码」。
真正的关键是 **提示词设计（Prompt Design）**。

好代码的 Prompt 要包含 3 个核心要素：
1️⃣ **角色设定（你希望模型扮演谁）**
2️⃣ **目标定义（你要实现什么）**
3️⃣ **约束要求（质量标准、风格规范、性能目标）**

---

## 🧩 二、通用高质量代码提示词模板

### 💡 模板

```text
你是一名资深的软件工程师，精通 {语言}。
请根据以下需求编写代码：
- 功能目标：{清晰描述需求}
- 技术要求：{框架/算法/库}
- 约束条件：{性能、可维护性、安全性、风格等要求}
- 输出格式：{是否包含注释、函数划分、类结构等}
请编写高质量、结构清晰、带解释性注释的代码。
```

### 🧠 示例

```text
你是一名资深 Python 工程师。
请实现一个高性能的 CSV 文件读取器，要求：
- 支持大文件流式读取；
- 能统计每列的缺失值数量；
- 使用 pandas；
- 输出示例运行结果。
代码需模块化、注释清晰。
```

## ⚙️ 三、针对「好代码」的专项提示词策略

### 1️⃣ 清晰结构（模块化 + 可读性）

```text
请将以下功能拆分成独立函数，每个函数职责单一，并添加 docstring 说明。
```

```text
请使用面向对象方式实现该逻辑，确保类的设计符合单一职责原则。
```

---

### 2️⃣ 代码风格与规范

```text
请生成符合 PEP8 风格的 Python 代码，并在命名上保持一致性。
```

```text
请输出符合 Airbnb JavaScript Style Guide 的实现。
```

```text
请重构以下代码，使其更符合 Google C++ Style Guide。
```

---

### 3️⃣ 可维护性与扩展性

```text
请编写易于扩展的实现，保留接口以便未来添加新功能。
```

```text
请在代码中添加必要的类型注解和异常处理，使其更易维护。
```

---

### 4️⃣ 性能优化导向

```text
请使用时间复杂度为 O(n log n) 或更优的算法实现此功能。
```

```text
请使用惰性求值或生成器的方式处理大数据，避免内存爆炸。
```

```text
请在输出代码后解释你的优化策略。
```

---

### 5️⃣ 安全与鲁棒性

```text
请确保所有外部输入经过验证，避免 SQL 注入或命令注入。
```

```text
请为此函数添加错误处理逻辑，防止异常导致程序崩溃。
```

---

### 6️⃣ 测试驱动与验证

```text
请为以下代码编写单元测试（使用 pytest / unittest），确保覆盖主要分支。
```

```text
请编写测试样例验证该算法在边界情况下的正确性。
```

---

### 7️⃣ 文档与注释

```text
请在每个函数上方添加 docstring，描述参数、返回值与逻辑说明。
```

```text
请在关键逻辑处添加行内注释，解释算法思想。
```

---

## 🧱 四、进阶组合 Prompt（让模型“像专家一样思考”）

### 🧩 示例 1：完整型

```text
你是一名资深 TypeScript 开发者。
请根据以下描述编写高质量代码：
功能：实现一个前端搜索栏，支持模糊匹配和防抖机制。
要求：
- 使用 React + TypeScript；
- 遵循函数式组件规范；
- 避免重复渲染；
- 包含完整注释与类型定义；
- 提供一份使用示例。
```

### 🧩 示例 2：思维链式

```text
先帮我分解实现该功能的步骤，再基于这些步骤生成高质量代码，并附上简要解释。
```

> ✅ 这样做能让 LLM 先“思考清楚结构”，再写代码，质量会更高。

## 🧭 五、小结表格

| 目标   | 提示词核心语句                        | 效果       |
| ---- | ------------------------------ | -------- |
| 清晰结构 | “拆分成独立函数并添加 docstring”         | 模块化、可读性高 |
| 风格规范 | “符合 PEP8 / Airbnb Style Guide” | 风格一致     |
| 可维护性 | “保留接口便于扩展”                     | 可拓展设计    |
| 性能   | “复杂度 O(n log n) 或更优”           | 高效算法     |
| 安全   | “验证所有外部输入”                     | 稳定可靠     |
| 测试   | “编写单元测试”                       | 质量保证     |
| 注释   | “添加 docstring 和关键行注释”          | 易理解      |
