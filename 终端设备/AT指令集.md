# AT指令集
AT命令集是由拨号调制解调器(MODEM)的发明者贺氏公司(Hayes)为了控制Modem发明的控制 协议.AT是Attention的缩写, 协议本身采用文本.每个命令均以AT打头,因此得名.
现在主要用于移动电话的操作

## 常用指令
    AT+CSQ
    命令解释：检查网络信号强度和SIM卡情况 

    ATZ
    命令解释：恢复原厂设置 

    AT+CGMR

## 打电话
    ATD{$电话号码};

## 信息

### 方法一    
    AT

    AT+CMGF=1

    AT+CMGS="{+区号电话号}" //ctrl+z 结束


### 发送中文使用 TEXT 模式
    #设置text模式
    AT+CMGF=1 //TEXT 模式

    #查看支持的编码
    AT+CSCS=?

    #选择一编码类型
    #我这里支持UCS2，所有选择了UCS2
    AT+CSCS="UCS2"
    #设置短消息文本参数  第四个参数：为0则只能发送英文,8为发送中文
    #默认是 17,71,0,0 用于其他英文字符集
    AT+CSMP=17,71,0,8

    #手机号码必须和选择的编码格式是一样的
    AT+CMGS="${手机号码}"

    #输入信息内容 发送短信,ctrl+z对应16进制为0x1A 
#### 例子
```
#查看支持的字符编码
输入> AT+CSCS=?
结果> +CSCS: ("IRA","GSM","UCS2")
#设置text模式
输入> AT+CMGF=1
结果> OK

输入> AT+CSCS="UCS2"
结果> OK

#设置短消息文本参数
输入> AT+CSMP=17,71,0,8
结果> OK

#设置手机号码18719301956
输入> AT+CMGS=""0038003600310038003700310039003300300031003900350036"
#内容内容你好
输入 > 4F60597D

结果>  +CMGS: 126
```
