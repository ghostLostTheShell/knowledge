##  创建新项目


## 使用 react-native 命令创建项目

* npx react-native init ${项目名称}

* npx react-native init ${项目名称} --version X.XX.X
    指定版本号

* npx react-native init AwesomeTSProject --template react-native-template-typescript
    --template来使用一些社区提供的模板，例如带有TypeScript配置的：


## 编译并运行 React Native 应用（android）
    切换到项目的根目录执行， yarn android 或 yarn react-native run-android
