# Electron+vue-cli3开发跨平台桌面应用 

## 环境
[Vue-cli]

安装：需要全局安装

```bash
npm install @vue/cli -g
```

[Vue]

[Electron]

## 创建项目

```bash
vue create electron-vue-demo

#添加 vue-cli-plugin-electron-builder
#home_page: https://www.npmjs.com/package/vue-cli-plugin-electron-builder

vue add electron-builder
```

## 配置 `vue.config.js`

```js
/**
 * 如果不加会报
 *  Uncaught ReferenceError: __dirname is not defined
 * **/
module.exports = {
    pluginOptions: {
        electronBuilder: {
            nodeIntegration: true
        }
    }
}

```
