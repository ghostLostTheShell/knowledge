#！ 指令概念

## 指令

### 描述：

    指令应用在模板的元素上

### 钩子函数
    bind

    inserted

    update

    componentUpdated

    unbind

    
### 子概念:

    全局指令

        使用 Vue.directive 创建


    局部指令

        创建组件时添加`directives` 

        directives: {
            指令名称: {
                inserted: function (el) {
                    el.focus()
                }
            }
        }
