# 组件
组件是可复用的 Vue 实例，且带有一个名字：

## 定义组件例子

```vue
// 全局注册,定义一个名为 button-counter 的新组件
Vue.component('新建组件名', {
  data: function () {
    return {
      count: 0
    }
  },
  template: '<button v-on:click="count++">You clicked me {{ count }} times.</button>'
})

//调用
<div id="components-demo">
  <新建组件名></新建组件名>
</div>

// 局部注册

new Vue({
  el: '#app',
  components: {
    'component-a': ComponentA,
    'component-b': ComponentB
  }
})

```
