
# 🟦 **字段语义规范**

下面是你项目里最常用、最核心的字段后缀语义规范。

---

# 🟩 **一、数量类字段（实体数量） → `_qty`**

表示 **真实的物理数量**，可数、可触摸。

适用于：

- 产品数量  
- 物料数量  
- 入库数量  
- 包装数量  
- 产量  
- 不良数量  

示例：

- `plan_qty`（计划产量）  
- `prod_qty`（生产数量）  
- `stockin_qty`（入库数量）  
- `pack_qty`（包装数量）  
- `reject_qty`（不良数量）  

👉 **制造业 / ERP / MES 的行业标准。**

---

# 🟧 **二、计数类字段（条数 / 次数） → `_cnt`**

表示 **事件次数、记录条数、统计次数**，不是实体数量。

适用于：

- 错误次数  
- 登录次数  
- 扫描次数  
- 报警次数  
- 订单条数  

示例：

- `error_cnt`（错误次数）  
- `scan_cnt`（扫码次数）  
- `order_cnt`（订单条数）  
- `retry_cnt`（重试次数）  

👉 **用于日志、事件、统计类字段。**

---

# 🟥 **三、编号类字段（编号 / 序号） → `_num`**

表示 **编号、序号、号码**，不是数量。

适用于：

- 订单编号  
- 行号  
- 设备编号  
- 工单编号  

示例：

- `order_num`（订单编号）  
- `line_num`（行号）  
- `device_num`（设备编号）  

👉 **不要用 `_num` 表示数量。**

---

# 🟦 **四、金额类字段 → `_amt`**

表示金额（amount）。

示例：

- `total_amt`（总金额）  
- `tax_amt`（税额）  
- `discount_amt`（折扣金额）  

---

# 🟩 **五、比率类字段 → `_rate`**

表示百分比、比率。

示例：

- `pass_rate`（合格率）  
- `completion_rate`（完成率）  

---

# 🟧 **六、时间类字段 → `_time` / `_at` / `_ts`**

### `_time` → 时长（duration）
- `wait_time`（等待时长）  
- `work_time`（工作时长）  

### `_at` → 时间点（timestamp）
- `created_at`  
- `updated_at`  
- `finished_at`  

### `_ts` → Unix 时间戳
- `start_ts`  
- `end_ts`  

---

# 🟥 **七、状态类字段 → `_state` / `_status`**

- `_state` → 简短状态（字符串）
  - `qc_state`  
  - `boxing_state`  

- `_status` → 更完整的状态（通常枚举）
  - `order_status`  
  - `task_status`  

---

# 🟦 **八、类型类字段 → `_type`**

表示分类、类型、模式。

示例：

- `order_type`  
- `model_type`  
- `error_type`  

---

# 🟩 **九、标志类字段（布尔） → `is_` / `has_` / `can_`**

示例：

- `is_active`  
- `has_error`  
- `can_retry`  

---

# 🟧 **十、ID 类字段 → `_id`**

表示外键或主键。

示例：

- `order_id`  
- `user_id`  
- `model_id`  

---

# 🟦 **终极对照表（最常用）**

| 后缀 | 含义 | 用途 | 示例 |
|------|------|------|------|
| `_qty` | 实体数量 | 产品/物料/产量 | `plan_qty` |
| `_cnt` | 次数/条数 | 日志/事件/统计 | `error_cnt` |
| `_num` | 编号/序号 | 编号类字段 | `order_num` |
| `_amt` | 金额 | 金额字段 | `total_amt` |
| `_rate` | 比率 | 百分比 | `pass_rate` |
| `_time` | 时长 | duration | `wait_time` |
| `_at` | 时间点 | created/updated | `created_at` |
| `_ts` | 时间戳 | Unix 时间戳 | `start_ts` |
| `_state` | 状态 | 简短状态 | `qc_state` |
| `_status` | 状态 | 完整状态 | `order_status` |
| `_type` | 类型 | 分类字段 | `order_type` |
| `_id` | 主键/外键 | ID 字段 | `order_id` |

---
