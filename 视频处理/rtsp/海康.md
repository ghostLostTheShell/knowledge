# rtsp 转 trmp
``` sh
ffmpeg  -rtsp_transport tcp -i \
"rtsp://{user}:{password}@{ip}//h264/ch1/main/av_stream" \
-vcodec copy -acodec copy -f flv \
"rtmp://{ip}/live/room"
```

## 海康摄像机回放的RTSP取流格式

海康摄像机回放的RTSP取流格式
```
rtsp://{username}:{password}@{ip}:{port}/Srteaming/tracks/{id :信道号}?parm1=value&...

# 参数：starttime, endtime
#
#
```


``` hs
ffmpeg -rtsp_transport tcp -i \
"rtsp://admin:lzm12345@192.168.1.217:554/Streaming/tracks/201?starttime=20200628t000000z&endtime=20200628t000100z” -vcodec copy -acodec copy -f flv “rtmp://localhost:1935/live/rooms”
```


## rtsp 转视频
```sh
ffmpeg -re -rtsp_transport tcp -i \
rtsp://user123:123456@192.168.1.220:554/h264/ch1/main/av_stream \
 -r 24 output.mp4
```

rtsp url 参数:

username：用户名，例如admin

passwd：密码，例如12345

ip：设备的ip地址，例如192.0.0.64

port：端口号默认554，若为默认可以不写

codec：有h264、MPEG-4、mpeg4这几种

channel：通道号，起始为1

subtype：码流类型，主码流为main,子码流为sub
