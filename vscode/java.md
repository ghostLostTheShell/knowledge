# java

安装 java Extension Pack

## 生成get-set方法

右键选择 `Source Action...`  的 `Generate set get`

## 重写方法

右键选择 `Source Action...` 的 `Override/implement Methods`

## 配置
[Java Extension Pack]
vscode 插件

[M2_HOME]
系统环境变量



在配置文件添加以下内容
```
"java.home": ${javahome目录},
"java.configuration.maven.userSettings": ${maven配置文件},
```
