# 默认快捷键

## 通用

`ctrl + shif + p` ：打开命令面板

`ctrl + p` : 打开文件

`ctrl + shift + n` : 新建窗口实例

`ctrl + shift + w` : 关闭窗口实例

`ctrl + n` : 新建文件实例

`ctrl + w` : 关闭文件

`ctrl + o` : 打开文件

`f11` : 全屏

`ctrl + t`: 搜索文件名称

## 编辑

`home` : 行首

`end` : 行尾

`ctrl + shift + k` : 删除整行

`ctrl + l` : 选中当前行

`alt + 上/下` ：将当前行上移或下移一行

`alt + shift + 上/下` ：将当前行的内容向上复制一行或向下复制一行

`ctrl + shift + o`: 当前文档符号搜索
