# 名义类型（Nominal Typing）

名义类型（Nominal Typing）是一种通过类型名称而非结构来区分类型的系统。它与 TypeScript 默认的结构类型（Structural Typing）形成对比，解决了结构类型在某些场景下的局限性。

## 核心概念
1. **类型标识**  
   每个名义类型都有唯一的标识符（通过 `Symbol.species` 实现），即使两个类型结构相同，只要名称不同就被视为不同类型。

2. **解决的问题**  
   ```typescript
   interface UserId { value: number }
   interface OrderId { value: number }
   
   const userId: UserId = { value: 123 };
   const orderId: OrderId = userId; // 无错误！结构相同
   ```
   上述代码在结构类型系统中不会报错，但逻辑上错误（订单ID与用户ID不可互换）。

3. **实现原理**  
   ```typescript
   type Nominal<T, Name extends string> = T & {
     readonly [Symbol.species]: Name; // 唯一标识
   };
   ```
   - `Symbol.species` 作为类型标签
   - 编译时类型检查 + 运行时标签验证

## 与结构类型的对比
| 特性         | 结构类型（TS默认）          | 名义类型                   |
|--------------|-----------------------------|----------------------------|
| **类型兼容** | 结构相同即可赋值            | 必须显式声明或转换         |
| **类型安全** | 逻辑错误风险高              | 逻辑类型安全               |
| **运行时**   | 无额外信息                  | 可保留类型标签             |
| **应用场景** | 快速开发、鸭子类型          | 金融/医疗等强类型领域      |

## 实际应用场景
1. **领域驱动设计（DDD）**  
   ```typescript
   type AccountNumber = Nominal<string, 'Account'>;
   type TransactionId = Nominal<string, 'Transaction'>;
   
   function transfer(from: AccountNumber, to: AccountNumber, amount: number) {
     // 确保只处理账户类型
   }
   ```

2. **物理单位安全**  
   ```typescript
   type Meters = Nominal<number, 'Meters'>;
   type Seconds = Nominal<number, 'Seconds'>;
   
   const speed = (m: Meters, s: Seconds) => m / s;
   
   // 编译错误：类型不匹配
   const result = speed(100 as Meters, 200 as Meters); 
   ```

3. **API 边界验证**  
   ```typescript
   type APIResponse<T> = Nominal<object, T>;
   
   function processResponse(response: APIResponse<'ValidAPI'>) {
     if (response[Symbol.species] !== 'ValidAPI') {
       throw new Error('Invalid API response');
     }
   }
   ```

4. **版本化数据类型**  
   ```typescript
   type UserV1 = Nominal<{ name: string }, 'UserV1'>;
   type UserV2 = Nominal<{ name: string, age: number }, 'UserV2'>;
   
   function migrate(user: UserV1): UserV2 {
     return { ...user, age: 0 } as UserV2;
   }
   ```

## 实现注意事项
1. **类型转换**：必须显式转换
   ```typescript
   const id = 123 as UserId; // 必须 as 转换
   ```
   
2. **运行时开销**：极小（仅多一个 Symbol 属性）
   
3. **序列化处理**：
   ```typescript
   const data = JSON.stringify(userId);
   const parsed = JSON.parse(data) as UserId; // 需要重新声明类型
   ```

## 在 Symbol.species 中的应用
`Symbol.species` 可用于实现名义类型（Nominal Typing），解决 TypeScript 结构类型的局限性：

```typescript
/**
 * 名义类型工具
 * @example 
 * type UserId = Nominal<number, 'UserId'>;
 * const id: UserId = 42 as UserId; // 必须显式转换
 */
export type Nominal<T, Name extends string> = T & {
  /** 名义类型的标识符 */
  [Symbol.species]: Name;
};
```

### 应用解析：
1. **类型安全**：
   ```typescript
   type UserId = Nominal<number, 'UserId'>;
   type OrderId = Nominal<number, 'OrderId'>;
   
   const userId: UserId = 123 as UserId;
   const orderId: OrderId = 123 as OrderId;
   
   // 编译错误：类型不兼容
   const invalid: UserId = orderId; 
   ```

2. **运行时校验**（结合装饰器）：
   ```typescript
   function validateId<T>(id: Nominal<number, T>) {
     if (typeof id[Symbol.species] !== 'string') {
       throw new Error('Invalid nominal type');
     }
   }
   ```

3. **解决结构类型局限**：
   ```typescript
   interface Vector2D { x: number; y: number }
   interface Vector3D { x: number; y: number; z: number }
   
   // TS 允许赋值（结构兼容）
   const v2: Vector2D = { x: 1, y: 2 };
   const v3: Vector3D = v2; // 无错误！
   
   // 名义类型解决方案
   type Vector2DNominal = Nominal<Vector2D, 'Vector2D'>;
   type Vector3DNominal = Nominal<Vector3D, 'Vector3D'>;
   
   const v2n = v2 as Vector2DNominal;
   const v3n = v3 as Vector3DNominal;
   v3n = v2n; // 编译错误！
   ```

### `Symbol.species` 的作用：
- 作为类型唯一标识符，避免不同名义类型间的意外赋值
- 提供运行时类型信息（通过 `id[Symbol.species]` 访问）
- 保持类型声明简洁（无需额外属性）
