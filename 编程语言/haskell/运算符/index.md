## 运算符
Haskell 的运算符非常丰富，可以分为几大类：

## 1. 算术运算符

```haskell
+    -- 加法
-    -- 减法  
*    -- 乘法
/    -- 浮点数除法
^    -- 乘方
^^   -- 分数乘方
**   -- 浮点数乘方
```

## 2. 比较运算符

```haskell
==  -- 等于
/=  -- 不等于
<   -- 小于
>   -- 大于
<=  -- 小于等于
>=  -- 大于等于
```

## 3. 逻辑运算符

```haskell
&&  -- 逻辑与
||  -- 逻辑或
not -- 逻辑非
```

## 4. 函数相关运算符

```haskell
.   -- 函数组合
$   -- 函数应用（低优先级）
&   -- 反向函数应用
>>> -- 正向组合
<<< -- 反向组合
```

## 5. 列表运算符

```haskell
:   -- 列表构造（cons）
++  -- 列表连接
!!  -- 列表索引
```

## 6. 类型相关运算符

```haskell
::  -- 类型标注
->  -- 函数类型或case分支
=>  -- 类型类约束
```

## 7. Monad/Applicative 运算符

```haskell
>>=   -- bind
>>    -- then
<$>   -- fmap (infix)
<*>   -- applicative apply
=<<   -- 反向 bind
```

## 8. 位运算运算符

```haskell
.&.   -- 位与
.|.   -- 位或
`xor` -- 位异或
`shift` -- 位移
```

## 9. 其他常用运算符

```haskell
`elem`    -- 包含检查
`notElem` -- 不包含检查
`div`     -- 整数除法
`mod`     -- 取模
`rem`     -- 取余
```

## 运算符优先级示例

```haskell
-- 从高到低优先级
2 + 3 * 4    -- 3*4先计算，等于14
(2 + 3) * 4  -- 2+3先计算，等于20

-- 函数应用优先级最高
show 2 + 3   -- 错误！show 2 返回字符串，不能与3相加
show (2 + 3) -- 正确
```

## 自定义运算符

Haskell 允许自定义运算符：

```haskell
-- 定义自定义运算符
(><) :: Int -> Int -> Int
x >< y = x * x + y * y

-- 使用
result = 3 >< 4  -- 9 + 16 = 25
```

## 常用运算符组合示例

```haskell
-- 函数组合
addAndShow = show . (+1)

-- 应用运算符
result = show $ 2 + 3  -- 等价于 show (2 + 3)

-- 列表操作
newList = 1 : 2 : 3 : []  -- [1,2,3]
combined = [1,2] ++ [3,4] -- [1,2,3,4]
```
