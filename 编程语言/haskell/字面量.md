
## 1. 整数字面量

```haskell
-- 十进制
a = 42
b = -123
c = 0

-- 十六进制（0x 或 0X 前缀）
hex1 = 0xFF        -- 255
hex2 = 0x1A        -- 26

-- 八进制（0o 或 0O 前缀）
oct1 = 0o77        -- 63
oct2 = 0o10        -- 8

-- 二进制（0b 或 0B 前缀）
bin1 = 0b1010      -- 10
bin2 = 0b1111      -- 15
```

## 2. 浮点数字面量

```haskell
-- 基本形式
a = 3.14
b = -2.5
c = 0.0
d = .5            -- 0.5（可以省略前面的0）
e = 5.            -- 5.0（可以省略后面的0）

-- 科学计数法
f = 1.23e4        -- 12300.0
g = 6.02e-23      -- 0.0000000000000000000000602
h = 1e6           -- 1000000.0
```

## 3. 字符字面量

```haskell
-- 基本字符
a = 'A'
b = 'z'
c = '0'
d = ' '           -- 空格
e = '\n'          -- 换行符

-- 转义字符
f = '\''          -- 单引号
g = '\\'          -- 反斜杠
h = '\t'          -- 制表符
i = '\"'          -- 双引号

-- Unicode 字符
j = '∀'           -- 全称量词符号
k = 'λ'           -- lambda 符号
l = 'π'           -- 圆周率
```

## 4. 字符串字面量

```haskell
-- 基本字符串
str1 = "Hello, World!"
str2 = "Haskell"
str3 = ""         -- 空字符串

-- 转义字符
str4 = "Line1\nLine2"
str5 = "Tab\tseparated"
str6 = "Quote: \"Hello\""
str7 = "Backslash: \\"

-- 多行字符串
multiline = "这是第一行\n\
            \这是第二行\n\
            \这是第三行"
```

## 5. 列表字面量

```haskell
-- 整数列表
list1 = [1, 2, 3, 4, 5]
list2 = []              -- 空列表
list3 = [1..10]         -- 范围：1到10
list4 = [1,3..10]       -- 范围：1,3,5,7,9

-- 字符列表
charList1 = ['a','b','c']
charList2 = ['a'..'z']  -- 所有小写字母

-- 字符串实际上是字符列表
str = "Hello"           -- 等价于 ['H','e','l','l','o']
```

## 6. 布尔字面量

```haskell
trueVal = True
falseVal = False
```

## 7. 元组字面量

```haskell
-- 不同类型元素的组合
tuple1 = (1, "hello")              -- (Int, String)
tuple2 = (True, 3.14, 'A')         -- (Bool, Double, Char)
tuple3 = ()                        -- 空元组

-- 嵌套元组
tuple4 = (1, (2, 3), "text")
```

## 类型注解

可以给字面量添加类型注解：

```haskell
-- 整数类型
a = 42 :: Int
b = 42 :: Integer    -- 大整数
c = 42 :: Word       -- 无符号整数

-- 浮点数类型
d = 3.14 :: Float
e = 3.14 :: Double

-- 指定列表类型
list = [1,2,3] :: [Int]
charList = "abc" :: String
```

## 特殊语法糖

```haskell
-- 列表推导式（也算一种字面量构造方式）
squares = [x*x | x <- [1..10]]           -- [1,4,9,...,100]
evens = [x | x <- [1..20], x `mod` 2 == 0] -- 偶数

-- 字符串连接
greeting = "Hello" ++ " " ++ "World!"    -- "Hello World!"
```

## 类型推断

Haskell 会自动推断字面量的类型：

```haskell
-- 默认整数类型是 Integer
num1 = 42        -- Integer

-- 默认浮点数类型是 Double
num2 = 3.14      -- Double

-- 根据上下文推断
add x y = x + y  -- 如果传入整数就是 Integer，传入浮点就是 Double
```
