# 函数

所有 Haskell 函数 本质上都是一元函数，多参数函数只是语法糖，靠柯里化和右结合来实现。

```haskell
f :: Int -> Int -> Int -- f::Int -> (Int -> Int)
f x y = x + y          -- f = \x -> (\y -> x + y) 定义展开
```

## 函数的模式匹配（pattern matching）

模式匹配是 Haskell 最重要的语法之一，它能让你对数据结构“按形状拆解”。
函数的不同定义通过“匹配输入的不同形态”来决定调用哪个分支。

```haskell
f :: Int -> String
f 0 = "零"
f 1 = "一"
f n = show n 
-- f _ = "其它数字"
```

匹配是从上到下进行的，只要匹配就停止。

## 匹配变量（variable patterns）

```haskell
f :: Int -> String
f x = show n 
```

## 匹配具体值（literal patterns）

```haskell
f :: Int -> String
f 0 = "零"
f _ = "忽略"
```

## 匹配元组（tuple patterns
```haskell
addPair :: (Int, Int) -> Int
addPair (x, y) = x + y
```
