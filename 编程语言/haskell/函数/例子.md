

## 1. let … in … 表达式的用法

**基本语法**

```haskell
let <定义块>
in  <表达式>
```

**使用案例**

```haskell

-- 计算圆的面积
circleArea :: Double -> Double
circleArea r = 
    let pi = 3.14159
        area = pi * r * r
    in area

-- 使用
result = circleArea 5  -- 78.53975

```

多个定义

```haskell
-- 解一元二次方程
solveQuadratic :: Double -> Double -> Double -> (Double, Double)
solveQuadratic a b c =
    let discriminant = b * b - 4 * a * c
        root1 = (-b + sqrt discriminant) / (2 * a)
        root2 = (-b - sqrt discriminant) / (2 * a)
    in (root1, root2)

```
---
```haskell
-- 计算 BMI 并给出分类
bmiTell :: Double -> Double -> String
bmiTell weight height =
    let bmi = weight / (height * height)
    in if bmi <= 18.5
        then "偏轻"
        else if bmi <= 25.0
            then "正常"
            else if bmi <= 30.0
                then "超重"
                else "肥胖"
```
