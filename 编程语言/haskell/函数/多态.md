# 函数多态

Haskell 中的多态本质上分成 两大类：

- 参数多态（Parametric Polymorphism）

- 特设多态 / 约束多态（Ad-hoc / Constrained Polymorphism）

这两种共同构成了 Haskell 函数的强大抽象能力。

## 1.参数多态（Parametric Polymorphism）

**定义**

函数对「类型参数」完全不关心，它对 所有类型都以同样方式工作。

- 示例1

    ```haskell
    id :: a -> a
    id x = x
    ```
    * a 是类型变量。
    * id 不关心输入是什么类型，只是返回它本身。

- 示例2 (map)

    ```haskell
    map :: (a -> b) -> [a] -> [b]

    ```
    * 无论 a、b 是什么类型，map 逻辑完全一样：遍历列表 + 应用函数。

**特点**

* 行为对所有类型一致（uniform）

* 没有类型类约束

* 是来自 System F 的纯 parametric polymorphism
