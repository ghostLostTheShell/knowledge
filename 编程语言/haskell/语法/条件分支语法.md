# 

## Guard 语法

```haskell
函数名 参数
    | 条件1 = 表达式
    | 条件2 = 表达式
    | otherwise = 表达式
```

## if-else 语法

```haskell
函数名 参数
    if 条件1 then 表达式
    else if 条件2 then 表达式
    else 表达式
```

## case of 语法

```haskell
case expression of
    pattern1 -> result1
    pattern2 -> result2
    pattern3 -> result3
    ...
```

**例子**

变量绑定

```haskell
processList :: [Int] -> String
processList xs = case xs of
    [] -> "Empty"
    (x:y:rest) -> "First two: " ++ show x ++ ", " ++ show y ++ "rest" ++ show rest
    [x] -> "Single: " ++ show x

```

守卫条件处理

```haskell
-- case + 守卫
grade :: Int -> String
grade score = case score of
    s | s >= 90 -> "A"
    s | s >= 80 -> "B"
    s | s >= 70 -> "C"
    s | s >= 60 -> "D"
    _ -> "F"

-- 等价的 if 表达式
grade' :: Int -> String
grade' score =
    if score >= 90 then "A"
    else if score >= 80 then "B"
    else if score >= 70 then "C"
    else if score >= 60 then "D"
    else "F"
```
