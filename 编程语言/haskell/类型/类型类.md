# 类型类（Type class）
声明了“能做什么”（一组函数）。类似rust的trait

## 1.标准库中的类型类

- Show： 提供 show :: a -> String 函数，将值转换为字符串。用于打印。

```haskell
show 123      -- "123"
show True     -- "True"
show [1,2,3]  -- "[1,2,3]"
```

- Eq： 提供 (==) 和 (/=) 函数，用于判断相等性。

```haskell
5 == 5    -- True
'a' /= 'b' -- True
```

## 2.定义类型类 (class)

使用 class 关键字。假设我们想定义一个描述“几何形状”的类型类。

```haskell
-- 定义一个名为 `Shape` 的类型类
class Shape a where
  area :: a -> Double      -- 计算面积的函数
  perimeter :: a -> Double -- 计算周长的函数
  -- 这里只有类型签名，没有实现
```

**建立实例关系**

```haskell
data Circle = Circle Double -- 定义一个表示圆的数据类型

-- 让 Circle 成为 Shape 的实例
instance Shape Circle where
  area (Circle r) = pi * r ^ 2
  perimeter (Circle r) = 2 * pi * r


data Rectangle = Rectangle Double Double -- 定义一个表示矩形的数据类型

-- 让 Rectangle 成为 Shape 的实例
instance Shape Rectangle where
  area (Rectangle w h) = w * h
  perimeter (Rectangle w h) = 2 * (w + h)
```

**使用**

现在我们可以编写一个通用的函数，它能处理任何 Shape 类型的值。

```haskell
-- 这个函数接受任何是 Shape 实例的类型 a
describe :: (Shape a) => a -> String
describe s = "Area: " ++ show (area s) ++ ", Perimeter: " ++ show (perimeter s)

-- 使用
main = do
  let myCircle = Circle 5.0
  let myRect = Rectangle 4.0 6.0

  putStrLn $ describe myCircle -- Area: 78.539..., Perimeter: 31.415...
  putStrLn $ describe myRect   -- Area: 24.0, Perimeter: 20.0
```

## 3.超类约束(superclass constraints)
一个类型类可以声明自己依赖于另一个类型类，这个被依赖的类型类就叫超类（superclass）。

语法

```haskell
class Eq a => Ord a where
    compare :: a -> a -> Ordering

```
- Ord a 是子类类型类

- Eq a => 是超类约束

- 意思：任何想成为 Ord 的类型 a，必须先是 Eq 的实例（可以比较相等）



### 3.1多个超类约束（Multiple Superclass Constraints）
一个类型类依赖多个类型类作为超类
```haskell
class (Eq a, Show a) => MyClass a where
    myFunc :: a -> String

```

## 4.自动派生 (deriving)

在 Haskell 中：

> **`deriving` 是让编译器自动生成某些类型类实例的机制**。

也就是说，你不用手动写 `instance Eq MyType where ...`，Haskell 会根据类型结构帮你生成实例。

---

**基本语法**

```haskell
data Color = Red | Green | Blue
  deriving (Eq, Show)
```

解释：

* `Eq` → 自动生成相等判断
* `Show` → 自动生成 `show` 函数
* 编译器根据数据构造子生成实现

效果等价于手动写：

```haskell
instance Eq Color where
    Red == Red     = True
    Green == Green = True
    Blue == Blue   = True
    _ == _         = False

instance Show Color where
    show Red   = "Red"
    show Green = "Green"
    show Blue  = "Blue"
```

---

## 4.1 可以自动派生的常用类型类

Haskell 内置支持自动派生的常见类型类有：

| 类型类                                    | 用途                   |
| -------------------------------------- | -------------------- |
| `Eq`                                   | 相等比较                 |
| `Ord`                                  | 排序比较                 |
| `Show`                                 | 转成字符串                |
| `Read`                                 | 从字符串读回值              |
| `Enum`                                 | 枚举（succ, pred）       |
| `Bounded`                              | 最小值/最大值              |
| `Generic`                              | 用于泛型编程（GHC.Generics） |
| `Functor` / `Foldable` / `Traversable` | 某些容器类型               |

> 注意：不是所有类型类都能自动派生，只有编译器支持的类型类。

---

# 4.2 派生规则

1. **对于和类型（Sum type）**

```haskell
data Color = Red | Green | Blue deriving (Eq, Show)
```

* Eq：如果两个构造子相同就 True，否则 False
* Show：用构造子名字生成字符串

2. **对于积类型（Product type）**

```haskell
data Person = Person String Int deriving (Eq, Show)
```

* Eq：每个字段都必须 Eq
* Show：每个字段都调用 Show，再组合字符串

3. **字段类型也要支持对应类型类**

```haskell
data MyType = MyType [Int] Bool deriving (Eq, Show)
```

* `[Int]` 需要 Eq/Show 才能派生成功
* `Bool` 也需要 Eq/Show

> 如果字段类型没有实例，编译器会报错

---

# 4.3 派生优势

* 避免重复手动实现 Eq/Show/Ord 等
* 对简单 ADT 很方便
* 保持代码整洁，可维护性高

---

# 4.4派生限制

1. **不能派生自定义类型类**（传统 Haskell98）

   ```haskell
   data Color = Red | Green | Blue deriving (PrettyEq) -- ❌
   ```

   需要手动写 `instance PrettyEq Color where ...`

2. **复杂数据结构可能需要泛型派生**

* 现代 GHC 可以用 `DeriveGeneric` + `Generic` 自动生成
* 或者用 `DerivingVia` 高级技巧

---

# 4.5高级派生示例（GHC 扩展）

```haskell
{-# LANGUAGE DeriveGeneric #-}

import GHC.Generics

data Person = Person { name :: String, age :: Int } deriving (Eq, Show, Generic)
```

* `Generic` 派生后，可以用于泛型函数、序列化库、自动 JSON 转换等
