# 配置管理信息

## 查看npm库安装目录

```bash
npm root -g
```



## prefix
```bash
npm config get prefix
```

## 查看npm配置信息
```bash
npm config list
```
## 缓存

### cache路径配置信息
```bash
npm config get cache
```

###
清理缓存

```
npm cache clean --force
```

### 修改全局和缓存路径
```
npm config set cache "${path}\node_cache"
```
