# --

作用:

    当调用函数有对应的”强”符号,则调用,若无则会尝试寻找其”weak”对应的函数,若再无则编译会报错 找不到该函数
    相对于

## 声明

1. -

    void 弱函数名(const char *s) __attribute__((weak, alias("要引用函数名称")));

    语法：

    函数声明 __attribute__((weak, alias("要引用函数名称")))

    void fun1(const char *s) __attribute__((weak, alias("fun2")));
    如果 fun1 === 强符号则直接调用,否则调用fun2

2. weak_alias [宏]
