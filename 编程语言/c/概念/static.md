# static
[关键字]

修饰变量或函数
- 修饰变量

[前置知识]

在 `c` 中变量里面可分为存在全局数据区、栈和堆里。

例如：

```c
int a ; //a是全局变量，

int main()
{

int b ; // b是栈变量

int c* = (int *)malloc(sizeof(int)); // c是堆变量。

}
```
## 作用

- 对全局变量的修饰

  限制只能是本文件引用此变量

- 栈变量的修饰

  栈变量的生命周期延长到程序执行结束，加入static修饰之后，变量已经不再存储在栈中，而是和全局变量一起存储。同时，离开定义它的函数后不能使用，但如再次调用定义它的函数时，它又可继续使用， 而且保存了前次被调用后留下的值。

- 对函数的修饰

  只能被本文件中的函数调用，而不能被同一程序其它文件中的函数调用
