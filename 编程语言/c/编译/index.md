#

## 相关的文件
|后缀| |
|--|--|
|.c| 	C程序源代码，在编译之前要先进行预处理。|
|.i|	C程序预处理输出，可以被编译。|
|.h|	C程序头文件。（为了节省时间，许多源文件会包含相同的头文件，GCC 允许事先编译好头文件，称为“预编译头文件”，它合适情况下自动被用于编译。）|
|.s|	汇编语言。|
|.S|	有C命令的汇编语言，在汇编之前必须先进行预处理。|

## 编译过程

1. 预编译
gcc -E main.c –o main.i

2. 编译
gcc -S main.i
编译得到 main.s 文件

3. 汇编

gcc -c main.s

4.链接
gcc main.o
