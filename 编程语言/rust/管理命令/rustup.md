# rustup
 
 rustup 可以帮助我们安装不同版本的rust 编程需要的工具连，同时可以方便的进行不同版本
之间的切换


- 安装指定版本

  ```bash
  rustup install ${版本}
  ```

- 更新

  ```bash
  rustup update
  ```

- 版本切换

  ```bash
  rustup default ${版本}
  ```

- 查看安装的版本信息

  * 

  ```bash
  rustup toolchain list
  ```

  * 

  ```bash
  rustup show
  ```
