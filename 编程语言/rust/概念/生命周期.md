- input lifetimes（输入生命周期）：
  函数或者方法的输入参数的生命周期

- output lifetimes（输出生命周期）：
  返回值的生命周期

- lifetime bounds （生命周期限定）：
  生命周期限定能应用于类型或其他生命周期。'a: 'b read as 'a outlives 'b，意味着 'a活得比'b久，即只要'b还有效，'a也一定有效。
  
  例 ：
  ```rust
   fn f<'a, 'b>(x: &'a i32, mut y: &'b i32) where 'a: 'b {
     y = x;                      // &'a i32 is a subtype of &'b i32 because 'a: 'b
     let r: &'b &'a i32 = &&0;   // &'b &'a i32 is well formed because 'a: 'b
  }
  ```
