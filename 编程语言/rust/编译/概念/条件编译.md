## cfg

  - cfg属性宏

      例子

      在不同的系统编译不同的函数
      
      ```rust
      #[cfg(target_os = "linux")]

      fn get_os_info(){
        println!("linux");
      }
 
      #[cfg(target_os = "windows")]
      fn get_os_info() {
          println!("windows");
      }
      
      fn main() {
          get_os_info();
      }
      ```

  - 函数宏
  
  ```rust
  if cfg!(target_os = "windows") {
  // windows系统要执行的代码段
  } else if cfg!(target_os = "linux") {
  // linux系统要执行的代码段
  }
  ```
