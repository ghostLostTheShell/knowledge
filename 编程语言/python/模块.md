### 模块寻找规则

[sys.modules]

  当import一个模块时首先会在这个列表中查找是否已经加载了此模块，如果加载了则只是将模块的名字加入到正在调用import的模块的Local名字空间中。如果没有加载则从sys.path目录中按照模块名称查找模块文件，模块文件可以是py、pyc、pyd，找到后将模块载入内存，并加入到sys.modules中，并将名称导入到当前的Local名字空间。

[sys.path]
  Python在import其它模块时，是从sys.path中搜索的。
    sys.path的初始值会受到PYTHONPATH、PYTHONHOME,程序的主目录, 标准链接库目录和.pth文件的目录等环境变量的影响。

[sys.meta_path]
  sys.meta_path这个简单的来说就是可以实现 import hook 的功能， 当执行 import 相关的操作时，会触发 sys.meta_path 列表中定义的对象。 关于 sys.meta_path 更详细的资料请查阅 python 文档中 sys.meta_path 相关内容以及 PEP 0302 。

``` python demo
"""使用sys替换调http模块
sys.meta_path 中的对象需要实现一个 find_module 方法， 
这个 find_module 方法返回 None 或一个实现了 load_module 方法的对象
"""
import sys


class MetaPathFinder:

    def find_module(self, fullname, path=None):
        print('find_module {}'.format(fullname))
        return MetaPathLoader()


class MetaPathLoader:

    def load_module(self, fullname):
        print('load_module {}'.format(fullname))
        sys.modules[fullname] = sys
        return sys

sys.meta_path.insert(0, MetaPathFinder())

if __name__ == '__main__':
    import http
    print(http)
    print(http.version_info)

```
