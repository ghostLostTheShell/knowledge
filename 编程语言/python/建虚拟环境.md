# 虚拟环境

## 安装

``` bash
pip install virtualenv -i https://pypi.python.org/simple/
```

## 创建虚拟环境

``` bash
virtualenv ENV #默认

virtualenv -p /usr/local/bin/python2.7 ENV #参数 -p 指定python版本创建虚拟环境

virtualenv --system-site-packages ENV #参数 --system-site-packages 指定创建虚拟环境时继承系统三方库
```

## python3 默认自带不用安装

python -m venv env

## 编辑器自动载入venv

### code

在settings.json添加以下内容

```json
    "python.venvFolders": [
        "venv",
        "自定义目录"
    ]

```
