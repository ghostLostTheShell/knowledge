## 使用 `@Bean` 和 `@ConditionalOnMissingBean` 的加载顺序问题
```
public interface 接口 {
    ...
}


public class 实现1 implements 接口{
    ...
}

pblic class 实现2 implements 接口{
    ...
}

@Configuration
public 实现1配置类 {
    @Bean
    @ConditionalOnMissingBean
    public 实现1 接口Bean() {
        ...
    }
}

@Configuration
public 实现2配置类 {
    @Bean
    public 接口 接口Bean() {
        .... 
        // 如果返回值写的是接口类型 `实现1配置类` 的 
        //`@ConditionalOnMissingBean` 是无效的 返回类型必须是 `实现2`
    
}

```
