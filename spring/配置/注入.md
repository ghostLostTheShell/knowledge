## @EnableConfigurationProperties

作用： 使`@ConfigurationProperties` 注解的类生效。如果一个配置类只配置`@ConfigurationProperties`注解，而没有使用@Component，那么在IOC容器中是获取不到properties 配置文件转化的bean

``` java
@ConfigurationProperties("属性")
public class 注入属性 {
    @NestedConfigurationProperty // 注意：注入方式是通过set方法
    private Config config = new Config();
}

@Configuration
@EnableConfigurationProperties(注入属性.class)
public 配置类{
  //注入 属性
}

```

## @ConfigurationProperties

## @NestedConfigurationProperty 

```yml
配置:
  汽车:
    轮子: 4
    颜色: 黑色
  
```

```java
@ConfigurationProperties("配置")
class XxxConfig{
    @NestedConfigurationProperty // 注入对应的
    private 汽车 config = new 汽车();
}

class 汽车{
  private String 轮子;
  private String 颜色;

  public set轮子(String 轮子);
  public set颜色(String 颜色);
}
```
